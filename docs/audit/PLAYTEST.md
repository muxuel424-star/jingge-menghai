# 真人试玩记录表

用于 01 §10、03 §11、05 §9、06 §8、07 §8、08 §7 与 10 最终验收。每次试玩使用相同版本的新存档。保留本表空白直到有实际记录。

## 流程

1. 五位第一次玩的玩家各用一个空白存档，独立打开游戏。开始前只确认设备和录屏许可。观察员不解释鲸歌、鱼群和 Boss。
2. 从点“接今晚的班”开始计时。记录前 90 秒是否被噩梦碰撞、是否自行发现按住并松开鲸歌、第一次是否通关、达成时间、每次 Boss 尝试和受伤情况。
3. 结束后请玩家用自己的话说 Grok 为什么让别人走开。按是否表达怕被拒绝或怕别人离开记录。另记自主发现的三种生态互动、三种道具、一个地标及各自用途。
4. 对三名试玩者展示被打乱顺序的黑色剪影、机关截图和 20 次连续进食录音。记录角色和鱼的识别、危险区域选择、高对比下可读性、音效识别以及海图和 HUD 阅读。将图像与各关视觉报告对应。
5. 如首局过不了，记录失败点后继续在同一存档重试，直到过关或累计五次。统计回合中进食、探索、停顿、Boss 三段各用多少时间。用于地图节奏和伤害平衡。

## 实机记录
