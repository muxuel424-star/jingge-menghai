## 明确取舍与风险

1. 04称第四拍为收声点，现有02与实现以四拍乐句闭合（起唱后4×60/72秒）判定；维持已公示“圆环合拢时松手”，不把第4个音的起点3T误当4T。
2. 04既写ambient永不duck，又在混音节明确Boss时ambient×.5；保留更具体的混音节规则。
3. 07最终Perfect合唱与08五关集齐才解锁有交集；按照内容优先级采用“第五关第三阶段Perfect且五关旋律齐”，由sim发唯一事件。
4. 09零裸数字与数学/合成常量的实现存在差距；本轮报告不会把命名几个常量或仅grep几个数当完成。不能通过删除设计条款消掉缺项。
5. JS heap不含全部canvas、解码图像、音频、GPU资源，绝不当作总内存；headless Chrome不等同实体核显验收。
6. 音频变更主要风险：高密度Boss预警与babble抢每帧8声部；优先级/限声上限保留，离线压力脚本记录丢声次数，专属tell的主干优先发声。听觉舒适度仍要实际试听wav。
