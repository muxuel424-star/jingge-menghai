# v2 改造与验收记录

本次以 `docs/design/` 原文为依据实现。原文保持原样；冲突按 README 的优先级选择，未把文档里的排期或待确认条目当成用户的额外审批要求。

## 已接入的可玩流程

- 五张顺序解锁的派工单，每关六个浅梦节拍和三个深梦节拍。
- 浅梦：碰鱼收链、回月光井送梦、唱睡噩梦、三段心事及隐藏交互，找到碎片或六分钟后开放裂隙。
- 潜梦：八秒演出，可按 Esc 跳过片刻；送梦数量提高本局气息上限。
- 深梦：忆质成长三体型、体型门、三段旋律、两条捷径和机关。每关十四个补给点。
- 九种生物有不同轮廓、技能、预警与反制；八种道具，最多两个持续增益。
- 五位前辈共用三阶段框架，保留各自招式、歌门、乐器与台词。每阶段需要应答，之后猛扑；普通碰撞不能替代歌门。
- 四拍鲸歌按 72 BPM 的完整乐句判定，圆环在 3.333 秒合拢。提示统一为「圆环合拢时松手」，避免把第四拍开始误当结束。
- 八种角色动作、12×8 网格、发梢裙摆跟随、动作打断与短过渡；连续 J 会重新播放猛扑动作。
- 三层视差、各海远景、地形分块缓存、六项 HUD、纸面派工单与日报。
- 四音频总线、五条配乐层、五关调式及动作、捕食、受击、机关、Boss 音效。M 静音，暂停后保持静音设置。
- 珍珠升级、每局任务、图鉴、二十成就、纪念品、旧档迁移、无法写入时的内存档。记录种子及旋律身份，重开页面再潜梦也保留已知故事和旋律。

## 修复的阻塞问题

歌门之间冷却可能导致连续错拍软锁；Boss 没有食物却继续扣稳度；大体型碰撞尺寸没变；超时以茶碗体型进 Boss 无法成长；捷径入口埋在实体中；持续机关周期为零；未消费浅梦教学；结算重复计工资；重开页面后丢失旋律身份；连续猛扑停在最后一帧。

低体型超时进入竞技场时，仅放置足够到水缸级的有限标准晶体，需要实际游动拾取。常规进入竞技场不额外刷鱼。

## 文档冲突的取舍

- 玩家体型严格采用 02 的 0/1/2 三阶；06 的旧 3/4 阶标注不再作为玩家门槛。皇鱼为鲸宫级且需要破甲或绕后；鮟鱇只能完美歌后反杀。
- 浅梦节拍原表共 450 秒，仍保留其关卡内容，兜底时间按 02 的 360 秒执行；不添加强制等待。
- 旋律位置按 08 的专门收集章节放置。
- 升级采用价格表；各项价格之和为 1370，原文「总价 830」不成立。
- 遵守 HP、速度、伤害和密度表后，熟练输入脚本会比 12–15 分钟目标快很多。尚未以真人测试确认时长、首通率和 Boss 平衡，未通过时间锁伪造目标时长。

## 验证与边界

运行 `npm test`、`npm run test:smoke`、`npm run test:audio`、`npm run test:perf` 可复现。测试包括最大体型路径及收集点可达、万点碰撞、跨帧率回放、所有歌门结果、真实输入深梦成长和五场 Boss 通关、隐藏碎片交互、存档迁移与结算、浏览器六阶段及五关渲染、离线音频与性能采样。浏览器夹具切场景只证明渲染与集成，不冒充自然通关。

已测的 60 秒 headless Chrome 采样使用真正的 1920×1080 backing canvas。它不能代替实体核显、总纹理内存、真人试玩、视觉抽样、剪影盲测或剧情记忆测试；采样出现过场景切换尖峰，未声称无 GC 尖峰。

全新运行源文件包含约 2200 个汉字，低于 2500 字预算。单文件美术内嵌，合成音频无需下载；构建会拒绝超过 6 MB 的产物。无 Google Fonts。

## 素材与生成提示词

使用内置 image_gen，未使用外部 API 或 CLI 生图。最终运行素材：

- `assets/side/act-hero-atlas.webp`：1536×768，4×2 八姿态，透明底；对应元数据 `act-hero-atlas.json`。沿用大肥鱼的蓝发、女仆服、鲸尾和围裙。
- `assets/side/atlas-backgrounds.webp`：2048×680，五行远景；对应元数据 `atlas-backgrounds.json`。
- `assets/side/atlas-boss.webp`：1536×1024，3×2 五位前辈，第六格留空；保留原发色、服装与身份，统一为赛璐璐。

角色最终提示词要点：以项目 swimmer 角色作身份参考，生成均匀 4×2 网格，依次 idle / swim / dash / bite / sing / hurt / eat / celebrate；全部朝右，完整身体，透明底；日本二维赛璐璐，两段平涂，深蓝描边，保留圆头、蓝发、短鲸尾、女仆头饰和鲸鱼围裙；吃姿态鼓腮，庆祝举碗；禁止文字、水印、3D、渐变、辉光。之后只做图集尺寸、WebP 编码与透明边缘清理。

远景最终提示词要点：五条等高横向全景堆成图集，无文字、角色、鱼或可交互前景；统一低对比赛璐璐，两段大色块。五行依次为翡翠浅湾学校珊瑚、青花古渡窑炉沉船桥、幽影紫海窗框丝线晶体、玄墨熔渊钟楼夜班走廊、黄金圣殿鲸肋与钟楼；各行按 03 四色表，暗部占 70%、中调 25%、高光少于 5%；禁止粒子雨、霓虹、厚重泛光与写实。

Boss 最终提示词要点：以旧 rivals 图集前五位作身份参考，忽略第六位；等格 3×2 排列，保留金发哥特见习生、蓝发青花女官、紫发猫耳前辈、黑白棋盘女仆和橙发持灯女仆长，全部完整身体朝右，约一头两身比例；统一两段平涂、深蓝粗描边、简化金线、各自独立剪影；透明底，禁止厚涂、3D、渐变、发光粒子、文字或水印。
