# 地形与人物动作改进

针对「地图粗糙、人物动画不丝滑」的实机反馈修改。

## 地图

原标准椭圆岩体改为三套固定21点自然礁岸轮廓，真实碰撞和画面使用相同多边形。轮廓全部内接原椭圆，不侵占原游动路线，门和Boss布局不变。

五海各有自己的岩壁、船板与裂瓷、晶脉、玄武岩、鲸骨砌石材质。每块普通实体使用独立图集贴片与描边路径，保留沿真实边缘的石沿、明暗和断面。海床与顶部物理边界也实际绘制。800像素分块带3像素余量，最多保留6块。

补充沿真实表面摆放的珊瑚、沉船残骸、晶洞、热泉和鲸骨遗迹；大完整装饰与小簇错开。移除高对比、重复的大叉形珊瑚和帆船轮廓，压低远景放大比例，使用柔化光束与小幅前景水草，让人物更清楚。

## 动作

循环动作从逐格取帧改成独立连续相位、细采样缓存和相邻帧插值，循环首尾闭合。速度、播放速率、倾角与转身平滑变化；八个姿态对齐脸部锚点，淡出姿态保留自己的时间。转向经过短暂窄身，不直接整张镜像。

移动中吃小鱼只做局部吞咽，避免每口都切一次全身姿态。持续冲刺保留发尾动作；受击仍能打断，连续猛扑会正确重播。鲸宫待机使用相同连续采样。

取消自动吞小荧鱼的世界顿帧，保留主动大目标命中的短暂停顿。猛扑挥空不再抖屏，密集冲击使用峰值保持，避免反复叠加。顿帧期间同步插值坐标，避免来回播放上一小段位移。镜头前瞻和升阶缩放也作平滑处理。

## 验证

103项单测、38项浏览器集成检查通过。包含最大体型通道、全部收集点连通、五关输入通关、轮廓内接、渲染只读、循环相位、转身、受击打断、连续猛扑、被动吞鱼不顿帧和挥空不屏震。

同一组真实键盘输入录制旧版和新版：两海的游动、转身、停游、冲刺、猛扑、唱歌。初始位置使用场景夹具，不冒充完整通关。录制会额外增加编码负担，性能另作独立60秒采样。

最终独立1920×1080画布采样约59.9fps；模拟p95约1.7ms，绘制p95约2.1ms，主画布最多13次drawImage，首屏约744ms。角色帧和插值缓冲约69.34MiB；此数不代表整个应用总内存，也不替代实体核显验收。

## 美术文件和提示词

使用内置 image_gen 生成，保留已有主角、Boss身份与赛璐璐方向。运行素材：

- `assets/side/atlas-scenery.webp`，1440×960，3×2环境簇，透明底，元数据同名json。
- `assets/side/atlas-materials.webp`，1536×1024，3×2材质片，元数据同名json。

环境簇提示词：统一日本二维动画环境画法、两段主要明暗、深蓝描边、左上光源、丰富但清晰的内线；均匀3×2格，依次为翡翠珊瑚花园、青花瓷沉船残骸、紫晶洞、玄武岩热泉、鲸肋遗迹、海底旧教室。完整独立对象，窄底可贴地形，透明背景，禁止文字、边框、水印、角色、鱼、3D和厚重辉光。

材质片提示词：以上述环境簇作画风参考，均匀3×2满幅不透明材质，依次为珊瑚灰岩沉积层与贝壳化石、裂瓷木板、紫色矿脉、玄武岩、嵌鲸骨旧石墙、蓝色板岩。使用03各海配色、细自然材质线和克制的亮边；禁止统一大砖网格、粗肥倒角、巨大高反差裂缝、文字、水印、写实3D和发光泛光。图集贴片在各实体的实际轮廓内绘制。
