# 10 · 开发计划与验收

> 给执行方（Codex）的工作说明书。
> **每个里程碑结束时必须能 `npm run build` 并截图。** 不许出现「重构完成但跑不起来」的中间态。

---

## 0. 工作协议

### 0.1 每张任务卡交付物

1. **变更说明**：改了哪些文件、为什么、有没有偏离文档（偏了要写理由）
2. **测试输出**：`npm test` 与相关脚本的原始输出（不是「已通过」三个字）
3. **截图**：至少 1 张 before / after
4. **性能读数**：`tools/perf.cjs` 的 fps 与内存
5. **风险登记**：这次改动最可能在哪崩

### 0.2 禁止事项（全项目通用）

- ❌ 在一个提交里同时改玩法和改结构
- ❌ 新增文档里没有的系统、道具、敌人、Boss
- ❌ 在 `data/` 之外写魔法数字
- ❌ 在 `render/` 里改 sim 状态
- ❌ 用 `Math.random()`（除 `sim/rng.js`）
- ❌ 引入新依赖（ESLint 类工具除外，需先提）
- ❌ 「顺手优化」未被要求的部分

### 0.3 做不下去时

在任务卡下面写 `BLOCKED: <原因>` + 你试过的两条路，然后停下等确认。**不要自己发明一个折中方案。**

## M1 · 手感（4 天）

> 目标：**不动美术、不加内容**，只让「游、咬、吃、挨打、长大」这五件事爽。
> 这是玩家前 3 分钟唯一的判据，优先级高于一切内容。

### M1-1 移动与冲刺

| 项 | 内容 |
|---|---|
| 文件 | `src/sim/systems/movement.js`、`src/sim/entities/player.js` |
| 要求 | 惯性 `1-exp(-9dt)`（保留）；冲刺 355；转向 0.16s 甩尾；`tilt` 跟随 vy |
| 新增 | **入水/出水**：靠近水面顶部 60px 时速度 −20%，产生气泡 |
| 验收 | 垂直与水平速度手感一致；松手后滑行 0.35s 内停住 |
| 测试 | 单测：给定输入序列，3 秒后位置误差 < 1px |
| 风险 | 加速度过高导致镜头抖 → 加死区 |

### M1-2 猛扑与咬合

| 项 | 内容 |
|---|---|
| 文件 | `src/sim/systems/combat.js`、`src/sim/systems/feeding.js` |
| 要求 | 冷却 0.48s；前扑 275；咬合半径 +14；按住可连扑（每次 −6 冲刺） |
| 新增 | 命中顿帧 0.06s + 屏震 4 + 3 帧白闪；未命中只有 `biteWhiff` 音 |
| 验收 | 连扑 10 次不掉帧；命中与未命中的反馈差异一眼可辨 |
| 测试 | 单测：命中判定在 30/60fps 下一致 |
| 风险 | 顿帧实现成「停整个循环」会导致输入丢失 → 只停 sim 的实体推进，不停输入采样 |

### M1-3 吃与升阶

| 项 | 内容 |
|---|---|
| 文件 | `systems/feeding.js`、`render/fx.js` |
| 要求 | 摄取特效（向心螺旋 0.25s）；数字上浮；combo 每 4 连升八度音；升阶 1.2s 演出（`03` 8.1） |
| 验收 | 连吃 20 条不糊、不卡；升阶演出可按 Esc 跳到 0.5s |
| 测试 | 录制 20 连吃，检查粒子数 ≤ 120 |
| 风险 | 数字上浮太多导致画面脏 → 每 0.16s 最多一条 |

### M1-4 受击与容错

| 项 | 内容 |
|---|---|
| 文件 | `systems/combat.js`、`render/camera.js` |
| 要求 | 受击 1.0s 无敌 + 击退 230 + 上抛 −65；屏震 8；红边 1.5s；唱歌时受伤 ×1.5 |
| 新增 | **受击方向指示**：屏幕边缘一个短箭头，0.4s 淡出 |
| 验收 | 玩家永远知道「刚才谁打的我」 |
| 测试 | 单测：无敌期间不重复扣血 |
| 风险 | 击退把人推进地形 → 击退后立即 `resolveTerrain` |

## 最终验收（全部满足才算交付）

1. `npm run build` 出单文件，双击可玩，≤ 6MB
2. `npm test` 全绿，`npm run test:smoke` 零 console error
3. 五关全部可从标题走到 `DAWN`，无卡死
4. 五个 Boss 全部可击败，演出完整
5. 1080p 核显 ≥ 45fps，60s 无 GC 尖峰
6. 首屏 ≤ 3s
7. 存档：v1 迁移、关掉页面再开进度不丢
8. 色板采样 ≥ 85% 合规；剪影测试通过
9. 全游戏文本 ≤ 2500 字，无错别字
10. 一位没看过文档的试玩者，能在 15 分钟内通关第一关，并能复述「Grok 为什么凶」
