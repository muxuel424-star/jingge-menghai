# 06 · 生态与敌人

> 目标：玩家看一条鱼 0.8 秒内就能判断「能不能吃、会不会咬我、怎么吃」。
> 当前版本的问题是行为存在但读不出来——每条鱼都在动，但玩家不知道它在干什么。

---

## 1. 一句话规则

**每条敌人都必须同时具备四件事：**
1. **识别特征**（远看就能认，不靠文字）
2. **预警**（要打你之前，有 ≥ 0.7s 的可读预备）
3. **破绽**（打完必有 ≤ 2.2s 的软肋）
4. **反制**（玩家的正确应对只有一种，且必须能赢）

少任何一件，这条鱼就不许上线。

## 2. 生态层级

```
          ┌──────────┐
          │  执念 Boss │  每关 1 个，不吃，只安抚
          └────┬─────┘
               │
        ┌──────▼──────┐
        │ 巨口鮟鱇 abyss│  食物链顶端，反杀才可得
        └──────┬──────┘
               │
      ┌────────▼────────┐
      │ 赤甲皇鱼 royal   │  有甲，需破甲
      └────────┬────────┘
               │
        ┌──────▼──────┐
        │ 夜光鳐 manta │  高速滑翔 / 涡流
        └──────┬──────┘
               │
      ┌────────▼────────┐
      │  灯笼鱼 lantern  │  诱鱼 + 电击
      └────────┬────────┘
               │
        ┌──────▼──────┐
        │ 小荧鱼 fry   │  群游，食物基底
        └─────────────┘
   旁支：纸船水母（中立弹床）· 梦貘（偷梦）· 珊瑚守卫（固定反击）
```

**生态作用**（不是数值，是关系）：
- 小荧鱼是**货币**（忆质换算率最高、风险最低）
- 灯笼鱼是**陷阱**（它替你聚鱼，也电你）
- 夜光鳐是**交通**（涡流可以借力）
- 赤甲皇鱼是**考试**（绕后 / 破甲二选一）
- 鮟鱇是**处决**（唯一需要「定身 + 反杀」的演出型击杀）
- 梦貘是**惩罚**（贪心收梦链的代价）

## 3. 物种卡

### 3.1 小荧鱼 `fry`

| 项 | 值 |
|---|---|
| 出现 | 全关，成群（8–14 条/群） |
| 体型 | 26px，最亮的小点 |
| 忆质 / 稳度 | 3 / +6 |
| 行为 | 群游（正弦摆动）→ 受惊则整群四散 0.85s → 重新聚拢 |
| 预警 | 无（不攻击） |
| 破绽 | 一直有 |
| 反制 | 直接吃；或唱歌把它们吸过来（一次 7 条） |
| 生态 | 被灯笼鱼引诱、被鮟鱇吸食 |

**设计点**：小荧鱼是唯一会「被玩家吓跑」的鱼。它必须**跑得掉**，否则吃鱼没有满足感。跑速 = 玩家游速 ×0.63。

### 3.2 灯笼鱼 `lantern`

| 项 | 值 |
|---|---|
| tier | 1 | 忆质 12 / 稳度 +14 / 伤害 9 |
| 识别 | 头顶一颗暖黄小球（唯一暖色身体） |
| 行为循环 | `pulse`（4.3s 一次聚鱼）→ `flash`（0.85s 蓄电）→ `recover`（1.1s） |
| 预警 | 蓄电时灯球变白、半径 114px 虚线圈 |
| 破绽 | `recover` 1.1s，此时不会跑 |
| 反制 | 拉开到 114px 外，或趁 recover 咬 |
| 生态 | 吸引小荧鱼到身边（玩家可以蹲点吃） |

**设计点**：它是「双刃」——它的聚鱼对玩家是好事，它的电是坏事。玩家应该学会**利用它的聚鱼，躲开它的电**。

### 3.3 夜光鳐 `manta`

| 项 | 值 |
|---|---|
| tier | 2 | 忆质 30 / 稳度 +22 / 伤害 14 |
| 识别 | 最大的扁平剪影，翼展 85px，会发光 |
| 行为 | 大范围滑翔（正弦 ×1.7）→ 接近玩家时 `evade`（逃）→ `vortex`（0.72s 蓄力 → 涡流 1.8s） |
| 预警 | 蓄力时身体蜷成圆，圈半径 120 |
| 破绽 | `vortex` 结束后 0.6s 不移动 |
| 反制 | 涡流释放时不硬碰，绕外圈；或冲刺穿过（有 0.2s 无敌） |
| 生态 | 涡流会卷走小荧鱼（强迫玩家追） |

**设计点**：它是唯一「会逃」的可食物种，追它是一场小追逐战。

### 3.4 赤甲皇鱼 `royal`

| 项 | 值 |
|---|---|
| tier | 3 | 忆质 55 / 稳度 +30 / 伤害 18 |
| 识别 | 正面有浅色扇形护甲（划痕可见），体型 94px |
| 行为 | `guard`（正面朝你）→ `charge`（0.82s 蓄力）→ `rush`（0.52s 冲刺）→ `recover`（2.2s） |
| 预警 | 蓄力时护甲发白 + 一条 250px 红色冲刺线 |
| 破绽 | `recover` 2.2s；**背面永远没有护甲** |
| 反制 | ① 绕后直接吃 ② 正面猛扑两次破甲 ③ 冲刺闪避后回头咬 |
| 生态 | 冲撞会撞晕小荧鱼（一片可捡） |

**设计点**：这是全游戏第一个「有三种解法」的敌人，也是教玩家「体型不是唯一答案」的敌人。

### 3.5 巨口鮟鱇 `abyss`

| 项 | 值 |
|---|---|
| tier | —（**永不可直接吃**） | 反杀得 忆质 90 / 一颗大珍珠 |
| 识别 | 巨大、暗、只有一张嘴和一颗诱饵灯，体长 2.6 倍 |
| 行为 | `lurk`（几乎不动）→ `suction`（0.95s 蓄力，吸 1.9s）→ `lungeTell`（0.32s）→ `lunge`（0.38s）→ `recover`（2.0s） |
| 预警 | 吸时嘴前出现 7 条流向线；突袭前 0.32s 全身绷紧 + 红线 |
| 破绽 | `recover` 2.0s；被鲸歌 Perfect 定身 ≥ 2.0s |
| 反制 | 吸的时候往侧后方游（吸力只在正面 205px 锥形内）；定身后猛扑 → 吞食反杀演出 |
| 生态 | 会吃掉附近所有鱼（包括它自己引来的） |

**设计点**：它是「地盘的主人」。玩家第一次遇到它应该是**逃**，第二次才是**杀**。

### 3.6 纸船水母 `jelly`（中立）

| 项 | 值 |
|---|---|
| 行为 | 垂直浮动 |
| 交互 | 碰到弹起（`vy -385`），冷却 1.2s |
| 用途 | 垂直移动、躲机关、跳上高处拿碎片 |
| 伤害 | 0 |

### 3.7 梦貘 `tapir`（新增，第 3–5 关）

| 项 | 值 |
|---|---|
| 识别 | 灰白、圆胖、长鼻、闭着眼 |
| 行为 | 缓慢游向最近的梦鱼，接触即吞（每次 1 条） |
| 对玩家的威胁 | 会**叼走梦链尾部的 1–2 条** |
| 反制 | 唱歌会让它睡着（12s），睡着时可以撞开（无伤害，掉出被吞的梦鱼） |
| 为什么存在 | 给「贪心收长链」一个代价，同时给鲸歌一个非战斗用途 |

### 3.8 珊瑚守卫 `guard`（第 1–2 关，固定）

| 项 | 值 |
|---|---|
| 行为 | 不移动，玩家靠近 90px 时张开刺（0.4s 预警） |
| 反制 | 等它收回（1.6s），或从背后过 |
| 用途 | 教「节奏型通过」；也可用洋流冲过去 |

### 3.9 噩梦 `nightmare`（仅浅梦层）

| 项 | 值 |
|---|---|
| 行为 | 游荡 → 追最近梦鱼 → 叼散梦链 → 被唱则安抚度上升 |
| 安抚 | 唱歌覆盖时 `calm += 0.68/s ÷ size`，满 1 消散并吐出 2–6 条梦鱼 |
| 成长 | 吃梦鱼会变大（最多 ×1.9），越大越难安抚 |
| 反制 | 唱（主）、冲刺甩开（次）、把它引到洋流里（进阶） |

**设计点**：噩梦不是要「打死」，是要「唱睡」。玩家第一次成功安抚的瞬间，是全游戏第一个情感高点。

## 4. AI 状态机规范

```js
// 所有可食物种共享
{
  kind, x, y, vx, vy, dir,
  action,        // 见下表
  stateT,        // 当前 action 已持续
  tellT,         // >0 表示正在预警（渲染层画红圈/红线）
  cooldown,      // 下一次能放技能的倒计时
  stun,          // 鲸歌定身
  armored,       // 仅 royal
  eaten,         // 被吃标记
}
```

### 4.1 action 表

| action | 进入 | 每帧 | 退出 |
|---|---|---|---|
| `school` | 归位 | 正弦群游 | 受惊 → `flee` |
| `flee` | 设 `panic=0.85` | 背离威胁 | panic 归零 → `school` |
| `pulse` | 记录 `lastLure` | 每 4.3s 聚鱼一次 | 玩家 < 210px → `flash` |
| `flash` | `tellT=0.85` | 定身、灯变白 | 0.85s → 放电 → `recover` |
| `glide` | 无 | 正弦大范围 | 玩家 < 240 → `vortex` 或 `evade` |
| `vortex` | `tellT=0.72` | 定身、蜷起 | 0.72s → 涡流 1.8s → `glide` |
| `guard` | `armored=true` | 朝向玩家漂浮 | 玩家 < 300 → `charge` |
| `charge` | `tellT=0.82` | 定身、甲发白、画冲刺线 | 0.82s → `rush` |
| `rush` | 锁定方向 | 直线冲刺 + 线段伤害 | 0.52s → `recover` |
| `recover` | 无敌关闭、甲关闭 | 慢速漂浮 | 时长到 → 初始 action |
| `lurk` | 几乎静止 | 极缓慢漂移 | 玩家 < 310 → `suction` |
| `suction` | `tellT=0.95` | 锥形吸力 | 1.9s → `lungeTell` |
| `lungeTell` | `tellT=0.32` | 绷紧 | 0.32s → `lunge` |
| `lunge` | 锁定方向 | 直线冲 520 | 0.38s → `recover` |
| `stunned` | 速度归零 | 抖动 | stun 归零 → 初始 action |

### 4.2 技能抢占

- 同屏最多 **2 个**敌人同时进入 `tell`/`rush`/`vortex`/`suction` 等「演出型技能」。
- 第 3 个请求被拒绝，进入 0.5s 后再试。
- 这防止「五条皇鱼同时冲脸」的不可读场面。

### 4.3 预警时长

| 敌人 | 预警 | 依据 |
|---|---|---|
| 灯笼鱼 | 0.85s | 人类反应 + 判断逃离方向 |
| 夜光鳐 | 0.72s | 可硬躲 |
| 赤甲皇鱼 | 0.82s | 需要判断「躲还是破甲」 |
| 鮟鱇吸食 | 0.95s | 必须能侧移出去 |
| 鮟鱇突袭 | 0.32s | 这是「已经躲不掉」的第二段，故意短 |
| Boss | 0.7–0.95s | 见 `07` |

## 5. 捕食判定

```
edible = tier(prey) <= tier(player)
```
额外规则：

| 情况 | 效果 |
|---|---|
| 从背后接触（`(p.x-prey.x)*prey.dir < -10`） | 伤害 ×1.4，无视正面护甲 |
| 猛扑命中 | 咬合半径 +14，可触发破甲 |
| 同一次猛扑已咬过 | 该敌人本帧不再判定（防双击） |
| 敌人处于 `recover` / `stunned` | 伤害 ×1.25 |
| 狂食中 | 伤害 ×1.25，但自己受击不减伤（旧版「狂食无敌」取消） |
| tier 不足接触 | 被该敌人按它的技能反击（不是固定伤害） |

**连吞**：2.8s 内连续进食累计 `combo`，每 4 连 +25% 分数，最高 ×4。分数**不影响**战斗数值，只影响评价里的一个副项。

**狂食**：连吞累积的「饱足感」满 100 → 7s 狂食（分数 ×2、速度 +12%、伤害 ×1.25、屏幕轻微暖色）。狂食期间**不会掉稳度**。

## 6. 涌现事件（生态不是背景板）

| 事件 | 触发 | 表现 | 玩家可做的事 |
|---|---|---|---|
| 惊群 | 玩家冲刺穿过鱼群 | 整群四散 0.85s | 追着吃，或唱回来 |
| 借鱼吃鱼 | 鮟鱇吸食 | 附近鱼被吸进它嘴里 | 趁它张嘴咬它的侧面 |
| 灯笼聚鱼 | 灯笼鱼 pulse | 小荧鱼被引到它身边 | 蹲点，吃一片 |
| 冲撞惊鱼 | 皇鱼 rush | 路径上的小荧鱼被撞晕 1.5s | 捡漏 |
| 梦貘蹭链 | 梦貘接触梦链 | 叼走尾部 1–2 条 | 唱睡它，撞回来 |
| 尸体引腐 | 任何鱼被吃 | 残渣 3s 内吸引 2–3 条同类 | 连锁吃 |

**规则**：同一时间最多 2 个涌现事件生效，避免画面失控。

## 8. 验收清单

- [ ] 每条鱼在剪影测试里能被区分（64px 纯黑）
- [ ] 所有攻击前 100% 有 `tellT`，且渲染层画了对应预警
- [ ] 同屏演出型技能 ≤ 2
- [ ] 玩家不看 UI 也能判断「这条能不能吃」（头顶色点保留，但改用「可吃=青点 / 不可吃=红点」两个状态，不加文字）
- [ ] 被不可吃的鱼攻击时，伤害来源与预警一致（不许「看不见的东西咬我」）
- [ ] 噩梦安抚成功有明确的正反馈（音效 + 吐梦 + 画面暖）
- [ ] 梦貘偷梦时玩家能理解发生了什么（一条弹字「它叼走了你的梦」）
- [ ] 所有物种在 30fps 下预警不丢帧
