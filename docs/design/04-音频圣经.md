# 04 · 音频圣经

> 现状：`src/audio.js` 全部 WebAudio 现场合成，方向是对的（零素材、可动态、体积小），**保留**。
> 问题：音效不成调、Boss 与杂兵音色无差别、没有 BGM 分层、鲸歌只有一条长音。
> 本文档把它从「音效库」升级成「配乐系统」。

---

## 1. 架构

```
                  ┌────────────┐
   oscillator ──► │  voice     │──► sfxBus ──┐
   noise      ──► │  (pool 56) │             │
                  └────────────┘             ▼
                  ┌────────────┐        ┌─────────┐   ┌───────────┐
   stems      ──► │  musicBus  │──────► │ master  │──►│ compressor│──► out
                  └────────────┘        │  gain   │   └───────────┘
                  ┌────────────┐        └─────────┘
   ambient    ──► │ ambientBus │             │
                  └────────────┘             ▼
                                        ┌─────────┐
                                        │ reverb  │◄── send (0.6)
                                        └─────────┘
```

| 总线 | 默认增益 | 说明 |
|---|---|---|
| `sfxBus` | 0.9 | 短音效，带并发上限 |
| `musicBus` | 0.55 | 分层 BGM，可整体 duck |
| `ambientBus` | 0.45 | 常驻环境铺底，永不 duck |
| `voiceBus` | 0.7 | 角色「叽里咕噜」说话音 |
| `master` | 0.9 | 总音量，静音即归零 |

**硬规则**
- 所有声音必须**走总线**，不允许直连 `destination`（现状有直连，必须改）。
- 所有音效时长 ≤ 1.5s，长音走 `musicBus`。
- 单帧新增 voice ≤ 8；全局并发 ≤ 56（现有上限保留）。

## 2. 调性设计

全局基准 **D**。每关一个五声调式，Boss 战在同调式内加速。

| 关 | 调式 | 五音（Hz，A4=440） | 情绪 |
|---|---|---|---|
| 1 翡翠浅湾 | D 宫（大调五声） | 293.66 / 329.63 / 369.99 / 440.00 / 493.88 | 好奇、明亮 |
| 2 青花古渡 | A 羽（小调五声） | 220.00 / 261.63 / 293.66 / 329.63 / 392.00 | 惆怅、旧 |
| 3 幽影紫海 | F# 羽（偏高） | 185.00 / 220.00 / 246.94 / 277.18 / 329.63 | 漂浮、暧昧 |
| 4 玄墨熔渊 | C 羽（偏低） | 130.81 / 155.56 / 174.61 / 196.00 / 233.08 | 沉重、耗尽 |
| 5 黄金圣殿 | G 宫 | 196.00 / 220.00 / 246.94 / 293.66 / 329.63 | 庄严、温柔 |

**规则**
- 所有 SFX 的基频必须**落在当关五音的 ±3% 内**；打击类除外（噪声），但其滤波中心频率要避开人声刺耳区 2–4kHz。
- 不许出现半音阶经过音。
- 低音区（< 120Hz）只允许 `sine`，禁止 `sawtooth`（会糊）。

## 3. BGM 分层

五条 stem，按状态交叉淡入（每条淡入 1.2s，淡出 0.8s）：

| stem | 内容 | 触发 |
|---|---|---|
| `pad` | 6 个失谐锯齿 + 低通 520Hz + LFO 0.05Hz | 常驻（现有 `startAmbient` 改造） |
| `pulse` | 每 2 拍的轻声拨弦（`triangle`，五音随机） | 玩家移动速度 > 30 时切入 |
| `tension` | 低鸣 55/58.3/82.4Hz + 心跳节奏 | 噩梦/敌人距离 < 300 |
| `deep` | 换调式 + 加一层 16 分音符的「水滴」点 | `DEEP` 状态 |
| `boss` | 4 小节循环，见 3.1 | `BOSS` 状态 |

**优先级**：`boss > deep > tension > pulse > pad`。高层不关闭低层，只 duck 低层到 30%。

### 3.1 Boss 层

- 速度：**84 BPM**（鲸歌仍是 72，制造「歌比伴奏慢」的压迫感）
- 4 小节结构：`bass（每拍）→ 铃（第 2/4 拍）→ 弦（长音）→ 鲸鸣（第 4 小节）`
- 三阶段：每阶段加一层
  - 阶段 1：bass + 铃
  - 阶段 2：+ 弦（八度叠加）
  - 阶段 3：+ 鲸鸣（降八度长音）+ 底鼓
- 阶段转换时**所有 stem 停 0.4s**，只留一声鲸鸣，然后三层一起回来

## 4. 鲸歌系统

### 4.1 节奏

```
BPM = 72   →   一拍 = 0.8333s   →   一乐句 = 4 拍 = 3.333s
```

- 按住 F/右键 **起唱**（0.15s 渐入）
- 屏幕下方 4 个点按拍闪烁；**第 4 拍最亮 = 收声点**
- 松开 = 收声判定：

| 判定 | 误差窗口 | 效果 |
|---|---|---|
| Perfect | ≤ 80ms | 定身 ×1.4、半径 ×1.3、冷却 ×0.6、+忆质 8、画面暖闪 |
| Good | ≤ 160ms | 定身 ×1.0、半径 ×1.0 |
| Miss | > 160ms | 定身 ×0.6、半径 ×0.85、气息额外 −10、Boss 可能反击 |

- 唱超过 2.2 倍（7.33s）自动收声 = Miss。
- 连续 3 次 Perfect → **共鸣**（8s）：梦鱼自动聚拢、鲸歌半径 +40%、画面持续微暖。

### 4.2 音高

起唱时随机取当关五音之一作为基频；每拍向上或向下走一个五音级（随机），形成「鲸鸣旋律」。
Perfect 收声时**额外补一个上八度泛音**（这是听觉上的奖励，必须做）。

### 4.3 对 Boss 的作用

- 每阶段有一次「歌门」：Boss 停止攻击、面向玩家、身上出现一圈音纹（1.2s 预警）
- 玩家必须在接下来 **4 拍内**完成一次 ≥ Good 收声
- Perfect → Boss 破防 2.4s（可打背部，伤害 ×1.4）
- Good → 破防 1.2s
- Miss → Boss 立刻发动一次「反击招式」（不进入冷却），并抵抗鲸歌 8s

## 6. 角色说话音（babble）

保留现有 `babble(pitch, n, type)`。每位角色固定参数：

| 角色 | pitch | type | 字数/句 | 说明 |
|---|---|---|---|---|
| 大肥鱼 | 1.25 | triangle | 6 | 软、慢 |
| Grok | 1.18 | square | 8 | 硬、快 |
| 千问 | 1.05 | triangle | 7 | 稳、拖 |
| Gemini | 1.35 | sine | 5 | 轻、断 |
| 智谱 | 0.84 | triangle | 6 | 低、匀 |
| Claude | 0.90 | sine | 7 | 最慢，几乎不 bb |

**规则**：一句台词 ≤ 8 个音；说话时其它 `babble` 被压到 0.3；台词文本见 `07`。

## 7. 混音

| 规则 | 值 |
|---|---|
| Boss 战时 `ambientBus` duck | ×0.5 |
| 玩家受伤时 `musicBus` duck | ×0.6，0.4s 恢复 |
| 鲸歌 Perfect 时 `sfxBus` duck | ×0.7，0.6s |
| 同 key 音效最小间隔 | 见表格「冷却」列 |
| 距离衰减 | 距离 > 500 的敌人音效音量 ×0.35；> 900 不播 |
| 声像 | `pan = clamp((x - 屏幕中心) / 屏幕宽, -1, 1) × 0.7` |
| 静音 | 立即 `master.gain = 0`，不销毁节点 |
| 暂停 | `ctx.suspend()`，恢复时 `resume()` |

## 8. 性能与兼容

- 所有合成节点在 `onended` 里 `disconnect()`（现状已做，保持）。
- 噪声 buffer 全局复用（已有 `sfxNoise`，保持）。
- 首次用户手势后才 `init()`（现有逻辑；保留，但要把「点开始」之前的静音状态提示做出来）。
- 不支持 WebAudio 时：全静音，**不报错、不阻塞游戏**。

## 9. 验收清单

- [ ] 任意两个音效同时播放不出现削波（compressor 生效）
- [ ] 所有 SFX 基频在当关五音 ±3% 内（用一个离线脚本扫频率表）
- [ ] 鲸歌 4 拍判定：Perfect/Good/Miss 三档在 60fps 与 30fps 下误差 < 1 帧
- [ ] Boss 阶段转换时能听到 0.4s 的「真空」
- [ ] 连续吃 20 条鱼不糊成一团（音量随 combo 上升但不超过 master 0.9）
- [ ] `M` 静音后，暂停/恢复不出现「幽灵音」
- [ ] 页面切到后台再回来，BGM 不断层
- [ ] 内存：AudioContext 节点数稳定，不随时间增长（Chrome 性能面板看节点数）
