# 05 · 世界与关卡设计

> 一关 = 一个梦 = 一个人。
> 每个梦都必须能被一句话讲清楚：「一个 ___ 的人，梦见了 ___。」

---

## 1. 关卡设计语法

### 1.1 六个节拍（Beat）

浅梦层固定 6 个节拍，每个节拍有**唯一一个**教学意图。禁止一个节拍教两件事。

| 节拍 | 意图 | 时长 | 玩家应该学会 |
|---|---|---|---|
| B1 醒着的海 | 建立安全区 | 90s | 游动、碰梦鱼、月光井 |
| B2 第一道影子 | 引入威胁 | 75s | 鲸歌安抚噩梦 |
| B3 流动的路 | 引入速度 | 75s | 冲刺 + 洋流 |
| B4 有人住过 | 引入叙事 | 75s | 找碎片、读环境 |
| B5 收不住 | 引入压力 | 75s | 保护梦链、取舍 |
| B6 裂隙 | 收束 | 60s | 潜梦 |

深梦层固定 3 个节拍：

| 节拍 | 意图 | 时长 |
|---|---|---|
| D1 反过来 | 建立「这是同一个地方」 | 90s |
| D2 长到能进去 | 体型钥匙 | 120s |
| D3 门前 | 升满 + 找旋律 | 90s |

### 1.2 地形四色编码（可读性硬规则）

| 类型 | 视觉 | 碰撞 |
|---|---|---|
| 可穿 | 无描边、比背景亮一档 | 无 |
| 实体 | 2px `ink` 描边、内部有两段明暗 | 实心 |
| 可破 | 描边 + 斜线纹 + 裂口动画 | 猛扑 2 次破 |
| 危险 | `fear` 描边 + 呼吸闪烁 | 接触扣血 |

**禁止**：同一屏出现两种以上「看起来能过其实不能过」的色块。这是当前版本最劝退的问题。

### 1.3 路径规则

- 主路径**永远只有一条**，宽度 ≥ 2.5 个玩家体型（鲸宫级也要能过）。
- 每条主路径上必须有 **1 个可选的上下绕行**（快 4s，但风险高）。
- 每关 **2 条捷径**，需要体型或道具解锁，回报是跳过 30–45s。
- 不许出现「只能前进不能后退」的死胡同（除 Boss 场）。

### 1.4 相机

- 浅梦层：横向跟随，垂直死区 ±28px
- 深梦层竖井段（L3 D2、L5 D2）：相机切纵向，前瞻改为 0.35
- Boss 场：相机锁定场地中心，只做呼吸式缩放（±0.03）

## 8. 秘密与收集

每关 **3 个梦的碎片** + **2 条捷径** + **1 个隐藏鲸宫纪念品**（纯装饰，放在鲸宫房间）。

| 类型 | 数量/关 | 回报 | 是否影响通关 |
|---|---|---|---|
| 梦的碎片 | 3 | 叙事 + 深梦层 +10% 忆质收益 | 否（但影响评价） |
| 捷径 | 2 | 省 30–45s | 否 |
| 纪念品 | 1 | 鲸宫房间装饰 + 成就 | 否 |

**评价**：结算评级 S/A/B/C 只看 **收集完整度 + 用时 + 受伤次数**，不看分数。分数在结算页作为副信息存在。

## 9. 关卡验收清单

- [ ] 主路径从头走到尾，鲸宫级体型不被卡住（自动脚本：沿路径点放 2.2 倍半径的圆做碰撞检测）
- [ ] 每个节拍的「教学意图」在首次进入时有一次性的提示（≤ 12 字），且只出现一次
- [ ] 同一屏内「能过 / 不能过」的视觉区分 100% 可辨（截图给 3 人盲测）
- [ ] 每个节拍都有 1 个「记忆点」（一个地标/一次演出/一句台词），能被人复述
- [ ] 深梦层的体型门失败时有明确反馈（撞上去弹回 + 一行字「太胖了……还是太小了？」）
- [ ] 碎片 3 条文案可读、无错别字、与委托人对得上
- [ ] 6 分钟保底裂隙开启生效
- [ ] 相机在任何位置都不穿地形（截图抽查 10 处）
