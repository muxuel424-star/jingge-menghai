# 03 · 美术圣经（赛璐璐）

> 目标：**一眼看出是「动画片截图」，不是「游戏素材拼贴」**。
> 当前版本最大的廉价感来源是：AI 生图切片 + 程序化发光叠加 + 描边不统一。这份文档逐条掐死。

---

## 1. 视觉关键词

深海 / 赛璐璐 / 两段明暗 / 粗描边 / 一盏暖灯 / 纸感 UI / 布料与发丝 / 暗部偏蓝紫

**画面优先级**：角色剪影 > 光源方向 > 地形可读性 > 氛围粒子。
任何特效如果让角色看不清，一律删除。

| `lamp` | `#FFD9A0` | 唯一的暖光色（灯、结算、暖心情节） |

### 2.2 五海

每海 4 色：`base`（底/暗部）`mid`（中调/体积）`hi`（高光/发光体）`soul`（情绪色，只点睛）。

| 关 | 海 | base | mid | hi | soul |
|---|---|---|---|---|---|
| 1 | 翡翠浅湾 | `#123A34` | `#2E8B72` | `#8FF0DC` | `#FFD9A0` |
| 2 | 青花古渡 | `#14283F` | `#2F6E9E` | `#A9D6F5` | `#F2E7CF` |
| 3 | 幽影紫海 | `#201436` | `#5B3A88` | `#C9A0FF` | `#FF9ED8` |
| 4 | 玄墨熔渊 | `#2A1417` | `#6E3229` | `#FFB27A` | `#FFE9A8` |
| 5 | 黄金圣殿 | `#211E19` | `#6E5A35` | `#FFE6A8` | `#FFF7DE` |

**深浅梦层差异**（同一张图，只换调色与光照，不换美术）：
- 浅梦层：`mid` 提高 12% 明度，`hi` 用作发光，整体对比 1.0
- 深梦层：`mid` 降低 18% 明度，暗部向 `ink` 压，对比 1.25，唯一光源改为单侧冷光 + 角色自身微光

### 2.3 禁止色

- 纯黑 `#000000`、纯白 `#FFFFFF`
- 霓虹紫粉渐变（`#FF00FF` 系）
- 彩虹/多色 HSV 渐变的能量球

## 3. 形状语言

| 对象 | 形状规则 |
|---|---|
| 鲸宫（家） | 圆弧 + 垂坠（穹顶、布幔、灯泡、盘碗） |
| 浅梦层地形 | 有机曲线，边缘软化，允许模糊 |
| 深梦层地形 | 断裂直线 + 大块负空间，边缘锐利，像记忆被撕开 |
| 梦鱼/梦 | 圆形 + 拖尾 |
| 噩梦 | 圆形被「咬掉一块」+ 尖刺 |
| 执念（Boss） | 三角形 + 严格左右对称（她们在硬撑） |
| 机关 | 直角 + 单一强调色，永远比背景亮一档 |

**可读性三色法则**（所有地形必须能归入其一）：
- `可穿`：不描边，只靠色块
- `可站/可撞`：描边 2px `ink`
- `可破坏`：描边 + 内部斜线纹

## 4. 角色规范

### 4.1 比例

| 角色 | 头身比 | 显示高度（逻辑 px） | 备注 |
|---|---|---|---|
| 大肥鱼（主角） | 1 : 1.2 | 128（茶碗）/ 192（水缸）/ 281（鲸宫） | Q 版，胖，尾巴短 |
| 前辈 Boss | 1 : 2.0 | 300–340 | 有威严但仍可爱 |
| 女仆长 | 1 : 2.2 | 360 | 最高，最安静 |
| 小动物 NPC | 1 : 1 | 40–80 | 剪影即可 |

### 4.2 描边

- 主角 **2px**（源图 1024 宽时约 5px，缩放后呈现 2px）
- 敌人 1.5px；Boss 2.5px（更重）
- 描边色 = `ink` 85% 不透明度，**不用纯黑**
- 内部结构线（比如裙褶）用删减版：只在受光侧断线

### 4.3 明暗

严格**两段**：
- 亮部 = 固有色
- 暗部 = 固有色 → 色相向蓝紫偏 8°，明度 −28%，饱和 −10%
- 高光 = 只允许「一条」：发丝一条、眼睛两点、金属一处
- **不允许**三阶以上的渐变塑造（会立刻变成 AI 厚涂感）

### 4.4 布料与发丝

每个可动部件分 3 层，振幅递减（`03` 只给规范，实现见 `09`）：
- 层 1（根部）：振幅 0.02，频率 ×0.6
- 层 2（主体）：振幅 0.05，频率 ×1.0
- 层 3（尾端）：振幅 0.09，频率 ×1.6
- 相位延迟：每层 +0.12 rad
- 速度越快振幅越大（上限 ×2.2），转向瞬间给 0.16s 的「甩尾」

### 4.5 剪影测试（硬性验收）

把角色缩小到 **64px 高、纯黑填充**，截图贴到 PR 里。要求：
- 主角：可辨认（圆头 + 短尾 + 围裙轮廓）
- 五个 Boss：彼此可区分（发饰/裙型/武器剪影差异）
- 不可辨认 → 重画，不许用配色补救

## 5. 动画规范

| 动作 | 帧数 | 帧率 | 循环 | 关键帧要点 |
|---|---|---|---|---|
| `idle` | 8 | 6 | 是 | 只有呼吸与尾鳍，头发位移 ≤ 3px |
| `swim` | 8 | 9–14（随速度） | 是 | 身体呈 S 形波，尾摆幅度最大 |
| `dash` | 6 | 16 | 否 | 第 1 帧压缩、第 3 帧拉长、第 6 帧回位 |
| `bite` | 6 | 18 | 否 | 第 2 帧张嘴最大（**必须停 1 帧**），第 4 帧合嘴 |
| `sing` | 12 | 10 | 是 | 嘴型 3 档循环，双手交叠在胸前，眼睛半闭 |
| `hurt` | 4 | 14 | 否 | 第 1 帧挤压 + 闪白，第 4 帧回位 |
| `eat` | 6 | 14 | 否 | 腮帮鼓起 → 吞咽 → 满足眨眼 |
| `celebrate` | 8 | 10 | 否 | 转圈 + 举碗 |

**动画三原则**
1. **预备帧**：所有有威胁的动作（猛扑、Boss 出招）必须有 ≥1 帧的预备姿态。
2. **可打断**：除 `hurt` 外的动作都能被更高优先级动作打断，打断规则见 `09` 的 `AnimPriority`。
3. **跟随**：结束帧要有 1–2 帧的「余势」（头发/裙摆延迟收），否则像贴图平移。

## 6. 镜头

| 参数 | 值 | 说明 |
|---|---|---|
| 前瞻 | 前进 0.41 / 后退 0.53 | 沿现有手感，保留 |
| 死区 | 水平 ±36px，垂直 ±28px | 防止微动抖镜头 |
| 跟随缓动 | `1 - exp(-dt*4.8)` | 保留现有 |
| 体型缩放 | `baseScale / (1 + tier * 0.06)` | 越大视野越广 |

| 垂直 | 允许 -64 上边距 | 竖井段必须有 |

## 7. 特效语言

四类，每类有形状、色彩、速度的硬规定。**不允许**新增第五类。

| 类 | 用途 | 形状 | 色 | 时长 | 备注 |
|---|---|---|---|---|---|
| 节奏 | 鲸歌、拍点 | 同心圆 + 4 条音纹 | `dream` | 0.3–0.9s | 线宽由内向外递减，不填充 |
| 冲击 | 猛扑、受击、破甲 | 白闪 2 帧 + 8 条放射短线 | `white` + `fear` | 0.08–0.18s | 短线带随机角度 ±12° |
| 摄取 | 吃、吸、收梦 | 向心螺旋 + 缩小消失 | 尸体的固有色 | 0.25s | 同时上浮数字（+忆质/+梦） |
| 情绪 | 稳度低、被吞、喜悦 | 全屏色偏 + 边缘暗角 | 随状态 | 持续 | **唯一允许的全屏后期** |

**绝对禁止**（当前版本泛滥，全部删除）：
- 多层加色发光圆（`globalCompositeOperation = 'lighter'` 叠 3 层以上）
- 屏幕空间泛光 / bloom
- 满屏飘落粒子雨（除背景气泡，且必须 < 60 个且在视差层）
- 渐变大光圈、彩虹描边
- 每个物体头顶都挂文字（改为靠近才显示）

## 8. 关键演出分镜

### 8.1 升阶（1.2s）
1. 0.0s：画面去饱和 → 0
2. 0.1s：白闪（`white` 70%），世界静止
3. 0.2–0.7s：旧体型礼服从肩线「炸开」成 12 片布片，向外飞散
4. 0.5–1.0s：新体型在中心出现，逆光，头发上扬
5. 1.0s：布片回吸成新裙摆，光收
6. 1.2s：恢复，播放 `celebrate` 前 2 帧

### 8.2 潜梦（8s）
1. 0–2s：角色停在裂隙前，镜头缓慢推近
2. 2–4s：裂隙内出现「那个人的记忆」——3 张静帧（手、窗、海）
3. 4–6s：角色被吸入，画面纵向拉丝
4. 6–7.5s：深梦层第一帧，色彩反转，声音先回来
5. 7.5–8s：出现一行小字（委托人的一句话），1.5s 后淡出

### 8.3 Boss 击败（4s）
1. 0–0.8s：顿帧 + 白闪，Boss 停止一切
2. 0.8–2.2s：Boss 缓缓坐下/跪下（**不是爆炸**），身上的尖刺软化
3. 2.2–3.2s：一句台词（字幕，无配音）
4. 3.2–4.0s：执念散成梦鱼，飞向月光井；画面回暖到 `lamp`

## 9. 背景与视差

三层 + 一层后处理：

| 层 | 视差系数 | 对比度 | 亮度 | 内容 |
|---|---|---|---|---|
| 远 | 0.20 | 40% | −35% | 大色块剪影（远山、沉船轮廓、巨骨） |
| 中 | 0.50 | 70% | −30% | 结构物（礁石、船肋、柱） |
| 近（地形） | 1.00 | 100% | 100% | 可交互地形 |
| 前景 | 1.35 | 60% | −55% | 少量遮挡（海草尖、气泡），每屏 ≤ 3 处 |

**顶部光柱**：从画面顶端斜 15° 打入，宽 180–260px，透明度 12%，只在中景与地形上生效。
**底部沉降物**：永远是缓慢上浮的小点，密度 ≤ 0.02/px²，颜色 `bone` 30%。

## 10. UI / HUD

风格：**鲸宫账房的纸面 + 朱红印章 + 青花细线**。禁止玻璃拟态、霓虹边框、渐变按钮。

| 元素 | 规范 |
|---|---|
| 字体 | 标题 `"STKaiti","KaiTi",楷体`；正文 `"Microsoft YaHei UI"`；数字 `tabular-nums` |
| **禁止** | Google Fonts（CJK 分片会卡 18s+，已知坑） |
| 纸面 | `paper` + 3% 噪点 + 右下轻微折角 |
| 分隔线 | 1px `#8FA3B5` 40%，虚线优先 |
| 印章 | `seal` 实心圆 + 白色字，旋转 −6° |
| 按钮 | 纸片凸起 1px 阴影，按下位移 1px |
| 强调数字 | `seal` 加粗，不用金色 |

### 10.1 HUD 只保留 6 项必读信息

| 位置 | 内容 | 形式 |
|---|---|---|
| 左上 | 名片：今晚的梦 + 进度 | 一张纸条，写「第2夜 · 老船匠」 |
| 左下 | 稳度 / 生命 | 一只饭碗：米量 = 稳度，碗沿红弧 = 生命 |
| 左下角 | 体型阶 | 碗旁边三只叠起来的碗（茶碗/水缸/鲸宫） |
| 下中 | 鲸歌节奏环 | 4 个点，第 4 点最亮；按住时展开 |
| 右下 | 气息 / 冲刺 | 两条细线，青与白 |
| 顶部中 | Boss 血条（仅 Boss 战） | 三段式，每段一道刻痕 |

**删除**：常驻分数、常驻珍珠数、连吞数字（改为吞食瞬间上浮）、区域名卡片（进区时一次性淡出）、箭头指引（改为雷达上一个小点）。

> 现有 `huntui.js` 的「身高尺 / 值班表 / 便签 / 饭碗 / 海图」五件套里，**只保留饭碗与海图**，其余并入 `DAWN` 结算页。

## 11. 素材交付规范

### 11.1 文件

- 格式：`webp`，质量 82，透明底
- 命名：`act-<角色>-<动作>.webp`，图集 `atlas-<类别>.webp`
- 图集：单张 ≤ 2048×2048，格子间留 2px 边距，**不要旋转打包**
- 锚点写在同一目录的 `<name>.json`：`{ "anchor": [0.5, 0.62], "pivot": [0.66, 0.51] }`

### 11.2 每个素材的生成规格（给生图/外包用）

| 文件 | 画布 | 内容 | 关键词 |
|---|---|---|---|
| `act-hero-idle.webp` | 1024×1024 | 大肥鱼女仆，正面 3/4，抱碗 | cel shading, thick outline, 2-tone, deep sea maid, chubby |
| `act-hero-poses.webp` | 2048×2048（4×2 格） | dash/bite/sing/hurt 各 2 帧 | same character, consistent palette |
| `atlas-fish.webp` | 1536×1024（3×2） | 小荧鱼/灯笼鱼/夜光鳐/赤甲皇鱼/噩梦/水母 | side view, strong silhouette |
| `atlas-boss.webp` | 2048×1536 | 五位前辈全身，同一比例同一光源 | full body, 1:2 proportions, rim light |
| `atlas-landmark.webp` | 2048×1024（3×2） | 月光井/礁棚/断桅/柱石/鲸骨拱/钟楼 | environmental prop, cel shading |
| `atlas-loot.webp` | 1024×1024（2×2） | 珍珠贝/宝箱/梦糖/海胆 | readable at 48px |
| `bg-bay.webp` 等 5 张 | 2560×1440 | 远景色块，**不含可交互物** | painterly, low contrast, silhouette |
| `island-*.webp` 5 张 | 1024×1024 | 单块地形，边缘必须闭合 | seamless-ish edge |
| `fx-song.webp` | 1024×256（4 帧） | 音纹 4 帧循环 | hand-drawn ink |

### 11.3 验收清单（逐条打勾才能进主干）

- [ ] 所有角色描边宽度在 1080p 下视觉一致（±0.5px）
- [ ] 只有两段明暗，没有第三阶渐变
- [ ] 剪影测试通过（64px 纯黑可辨）
- [ ] 调色板采样：随机取 20 个像素，≥ 85% 落在本关 4 色 ±8% 内
- [ ] 背景不含可交互物（防止玩家误判）
- [ ] 图集无旋转、无溢出、无 alpha 毛边
- [ ] 单张 webp ≤ 400KB
- [ ] 首屏加载总字节 ≤ 6MB
- [ ] 深梦层版本用同一素材、只换调色（不重新出图）
- [ ] 截图对比：新旧版本并排，新版本「看起来像动画」而不是「像素材堆」

## 12. 与当前版本的对照改造

| 现状 | 改成 |
|---|---|
| `swim-animation.js` 用 10×7 网格网格变形 | 保留（很好），但网格改为 12×8，并把振幅参数挪进 `tuning` |
| 主角只有 5 个姿态 | 增至 8 个（+ eat / celebrate / 潜梦） |
| 地形用 `islands` 图集平铺 + `formation` 多边形填充 | 全部改为「图集贴片 + 描边路径」，禁止用整张图平铺当纹理 |
| 机关用纯线条绘制（`environment()`） | 改为赛璐璐色块 + 描边，线条只做预警 |
| 背景单张平铺镜像 | 三层视差 + 光柱 + 沉降物 |
| 每帧 `globalCompositeOperation` 叠加 | 全项目搜索并删除（允许仅「情绪」类使用一次） |
