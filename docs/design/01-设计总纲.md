# 01 · 设计总纲

版本 v2.0 · 2026-11-26 · 适用于横版 2D 浏览器版

---

## 1. 一句话

> **你是鲸宫女仆「大肥鱼」，每晚拎着月光井去给睡不着的人送梦。
> 梦里的人有执念，执念会变成把你吞掉的巨兽——
> 你要把走失的梦一条条送回井里，再对着那团执念，唱对它那一夜的歌。**

## 2. 玩家体验目标

设计是否成立，用这三句话检验（玩家在第 3 / 8 / 15 分钟分别应该说出）：

| 时点 | 玩家应该说 | 由什么保证 |
|---|---|---|
| 第 3 分钟 | 「这鱼游起来好舒服，我想多游一会儿。」 | 手感、水流、镜头、环境音 |
| 第 8 分钟 | 「原来我变这么大，是为了钻进那道缝。」 | 体型=钥匙，不是数值 |
| 第 15 分钟 | 「刚才那首歌……我居然有点想哭。」 | Boss 与旋律的情感闭环 |

如果玩家说的是「挺好玩」「特效不错」「有点像饥饿鲨」，**说明设计失败了**。

## 3. 四个支柱

### 支柱一：温柔是手段，也是弱点
唯一的核心主动技能「鲸歌」，同时是：
- **最强的工具**（吸梦鱼、安抚噩梦、打断 Boss）
- **最脆弱的时刻**（移速 −45%、气息持续下降、受击伤害 +50%）

任何新增机制都必须回答：它怎么和这条张力互动。

### 支柱二：吃是为了进去，不是为了变强
捕食进化存在的唯一理由，是**体型作为空间钥匙**：某道梦的裂隙只有长到水缸级才挤得进去，某块压住梦鱼的石头只有鲸宫级才顶得开。分数和爽感是副产品，不是目的。

### 支柱三：每个梦都有主人
五关 = 五个真实世界的委托人 = 五种心结。玩家在浅梦层收集的「梦的碎片」拼出委托人的故事；Boss 不是敌人，是那个人用来保护自己的一层壳。**打赢 = 让她愿意松开手**。

### 支柱四：鲸宫是个真的工作单位
UI、结算、升级全部长在「女仆上班」这个隐喻上：派工单、日报小票、工资珍珠、前辈同事、退休交接。不许出现通用游戏 UI（血条红、金币黄、经验紫那套）。

## 4. 反支柱（明确不做）

| 不做 | 原因 |
|---|---|
| 饥饿鲨式的无尽刷分 | 分数不是目的；一局有头有尾 |
| 随机生成地图 | 每个梦必须有作者设计的节拍与记忆点 |
| 数值堆叠式成长（+5% 攻击 ×20 层） | 成长只走「体型阶」和「解锁能力」两条线 |
| 开放世界 / 五个海域自由往返 | 每局只进一个梦，边界清晰 |
| 弹幕海 / 满屏发光粒子 | 违反赛璐璐美术，且是当前版本最大的廉价感来源 |
| 通用 Roguelike 词条构建 | 不做 build 搭配，做「今晚这户人家」 |
| 长篇对白与过场动画 | 叙事靠环境、碎片、Boss 台词，总台词量 ≤ 2500 字 |

## 5. 世界观（够用就行，不写设定集）

- **鲸宫**：海底一座用鲸骨和沉船木搭的女仆宅邸，负责把「梦」分发到睡不着的人家里。女仆们按班次下潜。
- **月光井**：鲸宫发的制式道具，一盏提灯形状的井。梦鱼进去就变成那个人安稳的一觉。
- **梦鱼**：一个人散落的梦。人睡不着，是因为梦鱼走丢了。
- **噩梦**：梦鱼被「怕」污染后的样子。不邪恶，只是害怕；唱对了歌就会安静下来。
- **忆质**：梦的沉淀物。梦主人越放不下的东西，忆质越浓，凝成可以吃的结晶——所以**吃忆质 = 吃别人的心事**。这一条要在文案里点出来一次。
- **执念**：忆质堆积成的形体。每关的 Boss。
- **大肥鱼**：一条胖胖的、笨手笨脚、但唱歌很好听的鲸宫女仆。工牌上写着「见习」。

## 6. 角色阵容

五位前辈是**鲸宫的同事**，AI 名字保留为彩蛋，对外宣传不使用、不解释。

| key | 名字 | 岗位 | 外形关键词 | 心结 |
|---|---|---|---|---|
| `grok` | Grok 前辈 | 哥特见习生 | 黑红哥特裙、双马尾、一直在装凶 | 「怕生」 |
| `qwen` | 千问前辈 | 青花女官 | 青花瓷纹旗袍、抱着账本、礼数周全 | 「规矩是唯一能抓住的东西」 |
| `gemini` | Gemini 前辈 | 紫猫潜行者 | 猫耳、紫纱、走路没声音、爱玩捉迷藏 | 「游戏没结束，他就还会回来」 |
| `zhipu` | 智谱前辈 | 黑白执事 | 燕尾、棋盘纹、说话像下棋 | 「棋盘上至少规则公平」 |
| `claude` | Claude 女仆长 | 鲸宫首席 | 鲸骨发饰、暖金披肩、从不提高音量 | 「要有人接我的班」 |

> 设计红线：前辈**不是反派**。她们的攻击是「防御姿态」，不是恶意。所有招式名、台词、被击败演出都必须体现这一点。

## 7. 一局结构

```
标题
 └─ 派工单 BRIEF（选今晚去哪户人家，可跳过 30s）
     └─ 浅梦层 SURFACE（5-6 min）
         · 找梦鱼群、碰触收集、形成梦链
         · 躲/安抚噩梦
         · 收集 3 个「梦的碎片」
         · 找到梦的裂隙
         └─ 潜梦 DESCENT（8s 演出）
             └─ 深梦层 DEEP（4-5 min）
                 · 吃忆质，长体型（茶碗→水缸→鲸宫）
                 · 体型钥匙开地形
                 · 收集 3 段「旋律碎片」
                 └─ 执念 BOSS（2-3 min）
                     · 三阶段，每阶段一个「考」
                     · 鲸歌节拍破防 → 体型猛扑输出
                     · 场地乐器可撞响
                     └─ 天亮 DAWN（40s 日报小票结算）
```

**总计 12-15 分钟一局。** 重玩时 BRIEF 与 SURFACE 的第一段可跳过，压到 8 分钟。

## 8. 平台与体量

| 项 | 决定 |
|---|---|
| 平台 | 桌面浏览器（Chrome/Edge 优先），横屏；触屏可用但非首要 |
| 技术 | 现有 esbuild + Canvas2D + WebAudio，不引入引擎 |
| 分辨率 | 逻辑 960×540，渲染倍率上限 2 |
| 帧率 | 60fps 目标，最低 45fps（1080p 核显） |
| 单局时长 | 12-15 min |
| 总内容量 | 5 关 × (6 节拍 + 1 Boss)，无 DLC 预留 |
| 文本量 | 全游戏中文 **≤ 2500 字**（含 UI） |

## 9. 参考坐标

不是要抄，是告诉执行方「往这个水准靠」：

- **手感**：《Dandara》《Ori》的移动惯性 + 《Katana Zero》的顿帧
- **氛围**：《GRIS》的色彩情绪、《ABZÛ》的水体
- **叙事结构**：《Spiritfarer》的「每关一个人、一段告别」
- **Boss 演出**：《Cuphead》的预警清晰度、《Hades》的阶段转换
- **UI 隐喻**：《Papers, Please》的「小票即界面」

## 10. 成功判据（可测量）

| 判据 | 阈值 | 怎么测 |
|---|---|---|
| 新手 90 秒内不被噩梦撞到 | ≥ 80% 测试者 | 5 人试玩记录 |
| 玩家不看说明能发现「按住 F 唱歌」 | ≥ 70% | 试玩观察 |
| 单关通关率（首次） | 40-60% | 埋点/录屏 |
| Boss 战平均尝试次数 | 2-3 次 | 录屏 |
| 玩家能复述 Boss 的心结 | ≥ 60% | 试玩后访谈 |
| 帧率（1080p 核显） | ≥ 45fps | `tools/perf.cjs` |
| 单局内存 | ≤ 220MB | Chrome 任务管理器 |
| 首屏可玩时间 | ≤ 3s（本地） | 冷启动计时 |

## 11. 与当前版本的差异（改造清单）

当前 v1 的问题与本文档的处置：

| 现状 | 问题 | 处置 |
|---|---|---|
| 5 海一局连通，可来回走 | 没有「一局」的概念，节奏散 | 拆成 5 个独立梦，每局 1 关 |
| 送梦模式与捕食模式两个独立入口 | 两套游戏硬拼 | 合并为「浅梦/深梦」上下半场 |
| 6 阶体型，数值驱动 | 长得快但没有空间意义 | 3 阶体型，绑定地形钥匙 |
| 鲸歌 = 按住的蓄力条 | 正反馈弱，无音乐性 | 4 拍节奏环，Perfect 有强反馈 |
| 鱼群 AI 各写各的 | 玩家读不懂 | 统一「识别→预警→破绽→反制」语法 |
| Boss = 弹幕模式表 | 没人格、没演出 | 三阶段人格化，招式即台词 |
| 素材为 AI 生图切片 + 程序化拼接 | 廉价感 | 赛璐璐规范 + 分层背景 + 描边统一 |
| 音效全是短促合成音 | 不成调，吵 | 五声调内合成 + 分层 BGM |
| HUD 信息密度高 | 像模拟经营 | 收敛到 6 个必读信息 |

## 12. 文档缺项时怎么办

按优先级推导：
1. 这个决定会不会让玩家更「温柔」？会 → 采用。
2. 会不会让玩家更「贪吃」？会 → 拒绝或改造。
3. 会不会破坏 12-15 分钟的节奏？会 → 砍。
4. 以上都不适用 → 选实现成本低的那条，并在 PR 里标注。
