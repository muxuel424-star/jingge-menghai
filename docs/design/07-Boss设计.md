# 07 · Boss 设计

> 五位前辈**不是反派**。她们是梦主人用来保护自己的那层壳。
> 打赢不是「杀死」，是「让她愿意松开手」。
> 招式名 = 台词 = 她的心结，三者必须对上。

---

## 1. 通用框架

### 1.1 结构

```
入场 3s（不可操作，台词 1 句）
 ├─ 阶段 1（100%–66%）
 │   ├─ 基础招 A
 │   ├─ 基础招 B
 │   ├─ 招牌招（本阶段唯一）
 │   └─ 歌门（阶段转场触发）
 ├─ 阶段 2（66%–33%）  同上，招式加一档
 ├─ 阶段 3（33%–0%）   同上，加「终曲」招 + 场地变化
 └─ 击败演出 4s
```

### 1.2 通用数值

| 项 | 值 |
|---|---|
| 每阶段血量 | `SEG_HP[level]`，见下表 |
| 玩家造成伤害 | `19 + tier*10`，背袭 ×1.4，狂食 ×1.25，破甲窗口 ×1.25 |
| 体型门槛 | tier ≥ 1 才能造成伤害；tier = 2 时伤害 ×1.5 |
| 受击后无敌 | 0.32s |
| 招式预警 | 0.70–0.95s（阶段 3 最多 −0.07s） |
| 收招硬直 | 1.6–2.2s（阶段 3 最多 −0.16s） |
| 接触伤害 | 14 + level*5（只有在她出招/移动中） |
| 脱离战斗 | 玩家离开 940px 或隐藏 > 4.5s → 回位、清弹 |

| 关 | Boss | 每段 HP | 总 HP | 目标用时 |
|---|---|---|---|---|
| 1 | Grok | 160 | 480 | 90–110s |
| 2 | 千问 | 240 | 720 | 110–140s |
| 3 | Gemini | 320 | 960 | 120–150s |
| 4 | 智谱 | 400 | 1200 | 130–160s |
| 5 | Claude | 500 | 1500 | 150–200s |

### 1.3 歌门（每阶段一次）

1. Boss 停止攻击，转向玩家，身上出现一圈**4 拍音纹**（1.2s 预警）
2. 玩家在 4 拍内完成一次收声：
   - **Perfect** → 破防 2.4s（可打背，×1.4），播放专属音效
   - **Good** → 破防 1.2s
   - **Miss** → Boss 立刻发动「反击招」（不占冷却），并抵抗鲸歌 8s
3. 若玩家 4 拍内没有起唱 → 视为 Miss

**这必须是每阶段的高潮**：玩家会主动等歌门，而不是无脑砍。

### 1.4 场地乐器

每个 Boss 场有 1 类可撞响的物件。**撞响 = 用一次猛扑**（不是新按键）。

| 规则 | 值 |
|---|---|
| 触发 | 猛扑命中乐器 |
| 效果 | 见各 Boss |
| 冷却 | 8s（视觉上「断掉/碎掉」，冷却后复原） |
| 提示 | 靠近 160px 时乐器上有音纹呼吸 |

### 1.5 演出硬规则

- 招式预警必须**同时**有三种表达：画面（形状/线）、声音（专属 tell）、角色（预备姿态）。少一种就重做。
- 阶段转换时，**所有弹幕消失**，给玩家 1.2s 喘息。
- 击败时**不许爆炸**，要「坐下/跪下/松开」。
- 台词用字幕，不用配音；每 Boss ≤ 6 句。

## 2. 第一关 · Grok 前辈 ·「哥特见习生」

> 心结：**怕生**。她把自己打扮得很凶，因为凶一点就没人敢靠近，没人靠近就不会被拒绝。
> 场地：操场 · 校钟。地面是跑道，两侧有看台。

### 2.1 招式

| 招 | 阶段 | 预警 | 判定 | 伤害 | 收招 | 破法 |
|---|---|---|---|---|---|---|
| **三连猎袭** | 1/2/3 | 0.86s，红色冲刺线 | 3 段直线冲（610/650/700），每段 0.62s | 22+lv*6 | 1.8s | 冲刺侧闪；第 3 段后是最大破绽 |
| **深红震潮** | 1/2/3 | 0.80s，地面红圈 | 2/3/4 道扩张环（245） | 18 | 1.7s | 跳/游到环间隙 |
| **发夹扇形** | 1/2/3 | 0.70s，扇形虚线 | 2/3/4 波 × 3/3/5 枚（260） | 16 | 1.7s | 贴边，或从两波之间穿过 |
| **躲进看台**（招牌·阶段2） | 2 | 无预警（她跑了） | 消失 1.6s，从玩家背后冲出 | 24 | 1.4s | 听 babble 方向；她冲出来时背对玩家 → 背袭 |
| **「你别过来！」**（终曲·阶段3） | 3 | 1.0s，她蹲下抱头 | 全屏泪滴雨 0.9s，留 4 个安全点 | 20 | 2.0s | 站到光斑里（安全点有灯） |

### 2.2 歌门旋律

**D 宫 · 上行四音**：`D → E → F# → A`（第 4 拍收在 A）

### 2.3 场地乐器：校钟

撞响 → Grok 捂耳朵蹲下 **2.0s**，且这 2s 内她的护甲（那张凶脸）消失，伤害 ×1.25。
冷却 8s。

### 2.4 台词（6 句）

| 时机 | 台词 |
|---|---|
| 入场 | 「哟，新来的？……这边、这边归我管。」 |
| 阶段 2 | 「你怎么还没走啊！一般人早就跑了！」 |
| 歌门（被唱中） | 「……别唱了，好奇怪。」 |
| 阶段 3 | 「我不凶一点的话，你们都会走掉的。」 |
| 受击（背袭） | 「背、背后不算！」 |
| 击败 | 「……明天，还能一起上学吗。」 |

### 2.5 击败演出

不跪。她**坐下**，把双马尾解开，头发垂下来盖住脸。3.2s 时抬头，说最后一句。然后整个人散成一群小荧鱼，飞向校门口的光。

## 3. 第二关 · 千问前辈 ·「青花女官」

> 心结：**规矩是唯一能抓住的东西**。碗碎了，规矩还在，所以她守着规矩。
> 场地：窑心 · 青花瓷铃。圆形窑室，四周四只瓷铃。

### 3.1 招式

| 招 | 阶段 | 预警 | 判定 | 伤害 | 收招 | 破法 |
|---|---|---|---|---|---|---|
| **青花五连盘** | 1/2/3 | 0.78s，五条扇形线 | 3/4/5 波 × 5 盘（260） | 17 | 1.9s | 站在两盘之间的固定缝隙 |
| **回旋瓷刃** | 1/2/3 | 0.95s，环形虚线 | 2 波，飞出去再飞回来（275，1.06s 折返） | 19 | 2.0s | 折返前横移；或贴她身 |
| **碎瓷潮环** | 1/2/3 | 0.82s，地面裂纹 | 3/4/5 道环（250） | 18 | 1.85s | 环间隙，或撞瓷铃清场 |
| **立规矩**（招牌·阶段2） | 2 | 1.1s，画一条竖线 | 线左侧安全，右侧持续落瓷片 4s | 15/s | 1.6s | 待在左边（但 Boss 在右边，要等她过来） |
| **摔盘子**（终曲·阶段3） | 3 | 0.9s，她举起整摞盘子 | 全屏碎片，留下 3 个「完整盘」当掩体 | 22 | 2.0s | 躲到完整盘后面 |

### 3.2 歌门旋律

**A 羽 · 下行五音**：`A → G → E → D → C`（第 4 拍在 C）

### 3.3 场地乐器：瓷铃 ×4

撞响 **任意 2 只**（8s 内）→ 共振：全场飞盘碎裂、Boss 破防 1.8s、清空弹幕。
单独撞 1 只只有音效与 0.4s 硬直。

### 3.4 台词

| 时机 | 台词 |
|---|---|
| 入场 | 「擅闯窑心？请出示……算了，这里没有规矩可讲。」 |
| 阶段 2 | 「规矩不是为了管你们，是为了让我知道明天该做什么。」 |
| 歌门 | 「这一调……我记在账本第三页。」 |
| 阶段 3 | 「都碎了吧。碎了就不用再数了。」 |
| 受击 | 「……失礼。」 |
| 击败 | 「那只碗，本来是想送给他的。」 |

### 3.5 击败演出

她把最后一只完整的盘子放在地上，摆正，退后一步，鞠躬。盘子在她面前碎成粉，粉升起来变成梦鱼。

## 4. 第三关 · Gemini 前辈 ·「紫猫潜行者」

> 心结：**只要游戏没结束，那个人就还会回来找她**。所以她永远在玩捉迷藏。
> 场地：屋顶 · 风铃。屋顶有斜面和 6 只风铃，能躲到屋脊后。

### 4.1 招式

| 招 | 阶段 | 预警 | 判定 | 伤害 | 收招 | 破法 |
|---|---|---|---|---|---|---|
| **猫步潜行** | 1/2/3 | 消失，0.9s 后出现紫雾 | 从背后扑（650） | 21 | 1.6s | 听 babble；她扑空后 1.6s 背对 |
| **三重影袭** | 1/2/3 | 0.88s，三个紫圈标记 | 3/4/5 个落点，0.22s 后落下 | 19 | 1.8s | 站到没有圈的地方 |
| **尾巴横扫** | 1/2/3 | 0.75s，弧形紫线 | 半圆扫击，半径 220 | 24 | 1.65s | 贴地或跳到上方 |
| **玩线球**（招牌·阶段2） | 2 | 0.8s，她甩出线球 | 线球在场地弹跳 6 次，每次留下细线 | 14 | 1.8s | 线可以被猛扑切断（切 3 根她会被绊倒） |
| **炸毛**（终曲·阶段3） | 3 | 1.2s，全身紫电 | 全场电击 1.5s，屋脊后安全 | 26 | 2.0s | 躲屋脊后；或撞 3 只风铃提前打断 |

### 4.2 歌门旋律

**F# 羽 · 环绕三音**：`F# → C# → E → F#`（听起来像来回走，第 4 拍回到 F#）

### 4.3 场地乐器：风铃 ×6

撞响 **3 只**（6s 内）→ 她停下，耳朵竖起来，说一句「……你回来了？」并**停止攻击 2.5s**。
这是情绪破防，不是硬直：这 2.5s 内她的受击反馈改成「不敢还手」，伤害 ×1.5。

### 4.4 台词

| 时机 | 台词 |
|---|---|
| 入场 | 「喵～又来一个。你要不要陪我玩？」 |
| 阶段 2 | 「你躲得真好。他躲得也很好，躲了三年。」 |
| 歌门 | 「……这个调子，他哼过。」 |
| 阶段 3 | 「不许结束！结束了就没人来找我了！」 |
| 风铃 | 「……你回来了？」 |
| 击败 | 「喵……碗，还在窗台上吗。」 |

### 4.5 击败演出

她蜷起来，尾巴绕住自己，像睡觉。屋脊上出现一只碗的影子（光），碗里有半碗猫粮。她慢慢睡着了。

## 5. 第四关 · 智谱前辈 ·「黑白执事」

> 心结：**棋盘上至少规则公平**。现实里他被排班表磨平了，但棋盘不会骗他。
> 场地：天元星盘 · 铜钟。19×19 的棋盘地板，中央一口铜钟。

### 5.1 招式

| 招 | 阶段 | 预警 | 判定 | 伤害 | 收招 | 破法 |
|---|---|---|---|---|---|---|
| **黑白封路** | 1/2/3 | 0.92s，5 个落点圈 | 2/3/4 波 × 5 枚棋子直落（350） | 20 | 1.8s | 落点之间穿梭 |
| **星位震荡** | 1/2/3 | 0.88s，棋盘亮起十字 | 3/4/5 道环（275） | 18 | 1.75s | 环间隙 |
| **追子连落** | 1/2/3 | 0.72s，4 个追踪圈 | 4/5/6 波 × 3 枚追踪棋（395） | 17 | 2.0s | 引它撞墙/柱子 |
| **劫争**（招牌·阶段2） | 2 | 1.0s，两处同时亮 | 两次落子间隔 0.5s，封住 70% 空间 | 22 | 1.9s | 提前站到唯一空格 |
| **弃子**（终曲·阶段3） | 3 | 1.3s，他把自己的一枚棋子举起 | 整盘坍塌：全场落子 3s，只留 2 个安全格 | 24 | 2.2s | 安全格有微光；用冲刺抢 |

### 5.2 歌门旋律

**C 羽 · 稳定二音**：`C → G → C → G`（钟摆，第 4 拍在 G）。这关的歌门**更难**：二音相同，玩家必须靠拍子而不是音高。

### 5.3 场地乐器：铜钟

撞响 → 他停下落子（**不是破防**），说「……这一手，我没算到。」并获得 1.5s 停滞。
若在**他落子的同一拍**撞响 → 抢先手：他整轮不出招（3s），这是本关最高收益操作。

### 5.4 台词

| 时机 | 台词 |
|---|---|
| 入场 | 「踏入棋盘，这一步你走错了。」 |
| 阶段 2 | 「我算过所有可能。除了明天还要上班。」 |
| 歌门 | 「……这一曲不在谱上。」 |
| 阶段 3 | 「那就都别下了！棋盘也一起塌掉！」 |
| 受击 | 「……失礼了。」 |
| 击败 | 「……投子。这盘，我认输。」 |

### 5.5 击败演出

他把棋子一颗一颗收回棋盒，盖上盖子，坐下。棋盘边缘的光慢慢灭掉。他抬头笑了一下（全游戏唯一一次），然后散成梦鱼。

## 6. 第五关 · Claude 女仆长 ·「鲸宫首席」

> 心结：**要有人接我的班**。她不是要考你，她是怕没人可交。
> 场地：黄金圣殿 · 鲸骨琴。三根横贯场地的鲸骨琴弦。

### 6.1 招式

| 招 | 阶段 | 预警 | 判定 | 伤害 | 收招 | 破法 |
|---|---|---|---|---|---|---|
| **第一乐章 · 环潮** | 1/2/3 | 0.82s，环纹 | 3/4/5 道环（290） | 20 | 1.7s | 环间隙；或撞琴弦清场 |
| **第二乐章 · 织网** | 1/2/3 | 0.80s，网格亮起 | 4/5/6 波 × 5 枚织针（315） | 18 | 1.75s | 斜向穿网格 |
| **第三乐章 · 鲸袭** | 1/2/3 | 0.77s，她低头 | 3/4/5 段鲸形冲击（740） | 24 | 1.8s | 冲刺横移；每段之间 0.62s |
| **终乐章 · 星落** | 1/2/3 | 0.90s，天空变暗 | 3/4/5 波 × 5 颗星（420），留 3 个光斑 | 22 | 1.9s | 站光斑 |
| **擦灯**（招牌·阶段3） | 3 | 1.4s，她举起灯 | **全场变黑**，只有她灯光锥内可见，持续 6s | 26 | 2.0s | 跟着她的灯游；黑屏中她的出招预警改成声音 |

### 6.2 歌门旋律

**G 宫 · 完整五音**：`G → A → B → D → E`（第 4 拍在 D）。
这是全游戏最后一个歌门，**Perfect 会触发全场合唱**：所有已通过的四个 Boss 的旋律各响一句。

### 6.3 场地乐器：鲸骨琴 ×3

撞响 1 根 → 发出一声；若与玩家鲸歌**同一拍** → 合奏：Boss 破防 3.0s、全场清弹、画面金色。
单独撞 → 只有 0.5s 硬直与一声低音。

**这是全游戏唯一需要「歌 + 撞」同时成立的机关。**

### 6.4 台词

| 时机 | 台词 |
|---|---|
| 入场 | 「你来了。今晚是最后一班。」 |
| 阶段 2 | 「三十年了，我每天擦这盏灯。它比我更像我。」 |
| 歌门 | 「……唱得很好。我很久没听过了。」 |
| 阶段 3 | 「接住它。接不住也没关系，我再等一晚。」 |
| 受击 | 「嗯，力气够了。」 |
| 击败 | 「……明天，就交给你了。」 |

### 6.5 击败演出

她**没有倒下**。她把灯举起来，递给玩家。灯从她手里滑到玩家手里（3s，全程只有一盏灯在动）。她说最后一句。背景里鲸宫的走廊一盏一盏亮起来。她退到光外面，慢慢不见。

## 7. Boss 状态与代码契约

```js
boss = {
  key, level, hp, maxHp, segmentHp,
  phase,            // 1..3
  engaged, timer, recovery, invuln, resist, stun,
  attack,           // null | { skill, age, windup, fired, ... }
  dir, home,        // 回位点
  sequence,         // 招式轮转索引
  gate,             // null | { age, beats, openedAt } 歌门
  instrument,       // { x, y, r, cd }
}
```

**硬规则**
- `phase` 只增不减。
- 阶段转换时必须：清弹幕、清 attack、给 1.2s 硬直、播 `boss.phase` 音效。
- 歌门期间 `attack = null`，`gate` 存在，玩家输入照常。
- 歌门结束后必须重置 `resist`（否则玩家会连吃两轮歌门判定）。
- `defeatBoss` 必须：清弹幕、停 BGM 转 `dawn.bell`、锁输入 4s、写 `stats.downs[key]`。

## 8. 验收清单

- [ ] 每个招式都能在黑暗中（关灯看剪影）被识别出来
- [ ] 每次预警都能听到专属音效，且三种表达同时存在
- [ ] 歌门 100% 可触发、可完美、可失败，三种结果都有明确反馈
- [ ] 阶段转换时玩家有 1.2s 呼吸，不会在转换瞬间被打
- [ ] tier < 1 时打不出伤害，且有提示「长到水缸级才能伤到她」
- [ ] 背袭 ×1.4 生效，且背袭有独立音效与数字颜色
- [ ] 击败演出完整播放，可按 Esc 跳过，但跳过也保留台词字幕 2s
- [ ] 每个 Boss 的台词 ≤ 6 句，且每句都能对上心结
- [ ] 场地乐器撞响有反馈，冷却期视觉上「断掉」
- [ ] Boss 战 BGM 三阶段分层，转换时 0.4s 真空
