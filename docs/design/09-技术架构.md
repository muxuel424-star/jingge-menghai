# 09 · 技术架构

> 现状是能跑的：`src/side/*` 约 5.5k 行 + `src/{audio,meta,ocean-data}.js` 约 1k 行，esbuild 打单文件，Canvas2D。
> 问题不在能不能跑，在**改不动**：逻辑与绘制耦合、数值散落、地图是硬编码长数组、没有一行自动化测试。
> 这份文档的目标是：**在不推倒重来的前提下，把地基换成能支撑 5 关 + 5 Boss 精品的结构。**

### 2.1 分层规则（硬性）

| 规则 | 检查方式 |
|---|---|
| `sim/` 不许 import `render/`、`ui/`、`audio/` | 单测里 grep import 路径 |
| `render/` 不许写 sim 字段（`obj.x += ...`） | 代码评审 + `Object.freeze` 快照测试 |
| `data/` 不许 import 任何东西（除同目录 data） | 同上 |
| `data/` 之外不许出现裸数字（除 0/1/-1 和索引） | ESLint `no-magic-numbers` 或脚本扫描 |
| 单文件 ≤ 400 行 | CI 检查 |
| 每个 `sim` 函数必须能被单测直接调用（不依赖 `window`/`document`） | Node 环境跑 `npm test` |

## 3. 主循环

```js
// main.js
const STEP = 1 / 60;
let acc = 0;

function frame(now) {
  let dt = Math.min(0.25, (now - last) / 1000);
  last = now;
  acc += dt;
  let steps = 0;
  while (acc >= STEP && steps++ < 5) {
    game.step(STEP);      // 纯逻辑
    acc -= STEP;
  }
  render.draw(game, acc / STEP);   // 插值 alpha
  requestAnimationFrame(frame);
}
```

**规则**
- `sim.step` 内**不许**调用 `Date.now` / `Math.random` / `performance.now`；随机走 `rng`，时间走参数。
- 渲染插值：实体保留 `prevX/prevY`，绘制时 `lerp(prev, cur, alpha)`。
- 暂停 = 不推进 `acc`，但仍 `draw`（用于暂停画面）。

## 4. 事件总线

```js
bus.emit('eat', { kind, combo, x, y });
```

| 事件 | 载荷 | 订阅方 |
|---|---|---|
| `eat` | kind, combo, x, y | audio, fx, hud |
| `bite` | hit, target | audio, camera(shake) |
| `hurt` | by, amount | audio, camera, hud |
| `evolve` | tier | audio, fx, camera, ui |
| `song.start/beat/release` | quality, radius | audio, fx, hud |
| `dream.deliver` | count | audio, fx, hud, score |
| `boss.phase` | key, phase | audio, camera, hud |
| `boss.down` | key | audio, ui |
| `state.change` | from, to | ui, audio, save |
| `notify` | text, ttl | hud |

**理由**：现在 `audio.consume()` 在 `hunt.eat()` 里硬调。事件化之后，加一个「成就统计」或「录像」不需要改 sim。

## 6. 渲染

### 6.1 层

```
0  background-far      视差 0.20
1  background-mid      视差 0.50
2  terrain             视差 1.00（含地形描边）
3  entities            视差 1.00（鱼/角色/机关）
4  fx                  视差 1.00
5  foreground          视差 1.35（前景遮挡）
6  hud                 屏幕空间
```

### 6.2 性能预算（1080p，核显）

| 项 | 预算 |
|---|---|
| 总帧时间 | ≤ 22ms（45fps 下限），目标 16.6ms |
| `sim.step` 全部 | ≤ 3ms |
| 绘制 | ≤ 12ms |
| 每帧 `drawImage` | ≤ 260 |
| 每帧新建对象 | **0**（对象池） |
| 活跃粒子 | ≤ 120 |
| 同时敌人 | ≤ 28 |
| GC 停顿 | 无可见 |

### 6.3 规则

- 地形用**离屏 canvas 分块缓存**（每 800px 一块，进入范围才生成，离开 3 块后回收）。
- 视口外 200px 不绘制（现有 `visible()` 保留）。
- 所有 `createRadialGradient` / `createLinearGradient` **每帧最多 4 个**，且必须在离屏缓存里预生成（现状每帧新建，是主要开销之一）。
- 禁止在 draw 循环里写字符串拼接（`label()` 的文本用缓存 Map）。

## 7. 存档

见 `08` 第 5 节。实现要点：
- `ui/meta.js` 单例，构造时读档 → 迁移 → 校验 → 内存副本。
- 写档节流 500ms，且只在 `state.change` 与 `DAWN` 时 flush。
- 读档失败：全部落默认值，并在设置页显示降级提示。

## 9. 迁移路线（M0 具体怎么做）

**原则：每一步都能跑、能截图。**

| 步 | 动作 | 风险 |
|---|---|---|
| 1 | 把 `ocean-data.js` / `reefs.js` / `habitat.js` 的数值抽进 `data/tuning.js` 与 `data/levels/*`，**逻辑不动** | 低 |
| 2 | 把 `ecology.js` / `boss.js` 里的 `resolveTerrain` 与 `game.hurt` 调用改为通过 `ctx` 注入，便于单测 | 中 |
| 3 | 抽出 `sim/terrain.js`、`sim/math.js`，`view` 改为 import | 低 |
| 4 | 引入固定步长与 `rng`（先与现有随机并存，逐个替换） | 中 |
| 5 | `view.js` 拆成 `render/*`，先机械拆分，不改绘制逻辑 | 中 |
| 6 | 引入事件总线，把 `audio.*` 直接调用改成 emit | 低 |
| 7 | 加单测与冒烟脚本 | 低 |

**禁止**：在第 1 步就顺手改玩法。M0 的唯一目标是「行为完全等价 + 有测试」。

## 10. 代码规范

- 命名：`data` 用 camelCase，文件用 kebab-case，事件用 `域.动作`。
- 不允许 `export default`（命名导出便于 grep）。
- 不允许 `any` 式隐式结构：共享实体写 `typedef`。
- 注释只写「为什么」，不写「是什么」。
- 每个 `systems/*.js` 导出一个 `update(game, dt)`，且不返回新对象。
- 颜色只从 `render/palette.js` 取，不许内联 HEX。
- 所有面向玩家的字符串集中在 `data/dialogue.js`。
