# 02 · 核心循环与数值

> 本文档的**所有数字**都是口径。代码里只允许从 `src/data/tuning.js` 读取，禁止散落魔法数字。

## 1. 一局的状态机

```
        ┌─────────┐
        │  TITLE  │
        └────┬────┘
             │ 选模式
        ┌────▼────┐   可跳过（30s 上限）
        │ BRIEF   │   派工单：选今晚的梦
        └────┬────┘
             │ START
        ┌────▼──────────────┐
        │ SURFACE  浅梦层    │  5-6 min
        │ 收梦 / 躲噩梦 / 碎片│
        └────┬──────────────┘
             │ 集满 3 碎片 → 裂隙开启
        ┌────▼────┐
        │DESCENT  │   8s 不可操作演出
        └────┬────┘
        ┌────▼──────────────┐
        │ DEEP  深梦层       │  4-5 min
        │ 吃忆质 / 体型 / 机关│
        └────┬──────────────┘
             │ 进入执念领域（自动触发）
        ┌────▼────┐
        │  BOSS   │   2-3 min
        └────┬────┘
             ├──── 胜 ──┐
             └──── 败 ──┤
        ┌────▼────┐     │
        │  DAWN   │◄────┘
        └────┬────┘
             └──► TITLE / 下一关
```

**状态契约**（`sim/game.js` 里实现为枚举 + 单一 `transition(next)`）

| 状态 | 可输入 | 时间推进 | 暂停菜单可用 | 必须存在的数据 |
|---|---|---|---|---|
| `BRIEF` | 选择/确认 | 否 | 否 | `meta` |
| `SURFACE` | 全部 | 是 | 是 | `surface` |
| `DESCENT` | 无 | 演出计时 | 否 | `surface`（冻结） |
| `DEEP` | 全部 | 是 | 是 | `deep` |
| `BOSS` | 全部 | 是 | 是 | `deep` + `boss` |
| `DAWN` | 结算按钮 | 否 | 否 | 统计快照 |

**硬规则**
- 任何状态切换都必须先 `cancelHeld()`：清空按住状态、停鲸歌、清输入集合。
- `DESCENT` 期间即使玩家按键也不能动，但可以 `Esc` 跳过演出。
- `DAWN` 不可重入；重复调用 `finish()` 必须被忽略（现有代码有 `ended` 保护，保留）。

## 2. 资源表

| 资源 | key | 范围 | 涨 | 落 | 归零后果 |
|---|---|---|---|---|---|
| 生命 | `hp` | 0–maxHp | 吃忆质 +1/口、海葵药剂 | 受击 | 失败（`DEVOURED`） |
| 梦稳度 | `stability` | 0–100 | 吃忆质 +food | 每秒 −1.1（深梦层） | 失败（`FADED`） |
| 气息 | `breath` | 0–maxBreath | 不唱时 +9/s | 唱歌 −16/s | 不能唱；浅梦层扣稳度/生命 |
| 冲刺 | `dash` | 0–100 | +22/s | 冲刺 −34/s | 不能冲刺 |
| 忆质 | `mem` | 0–∞ | 吃忆质 | — | — |
| 梦链 | `chain` | 0–12 | 碰触梦鱼 | 送回井 / 被叼散 | — |
| 珍珠 | `pearls` | 0–∞ | 结算、宝箱、任务 | — | — |
| 鲸歌 | `song` | 相位 0–4 拍 | 按住 F 起唱 | 松开/气息尽 | — |

> **梦稳度的语义**：深梦层是别人正在散掉的梦。你吃忆质是在「稳住这个梦」，也是在「吃掉别人的心事」。画面随稳度下降而褪色（`03` 有对应参数），这是唯一需要做全屏后期的地方。

### 2.1 气息上限

```
maxBreath = 100 + min(32, floor(surfaceDreamsDelivered / 10) * 8)
```

浅梦层每送回 10 条梦鱼，深梦层多 8 点气息，最多 +32。这是两个半场之间**唯一**的正向传递。

### 2.2 冲刺与气息的关系

- 冲刺**不消耗**气息（旧版消耗，已删除）。
- 浅梦层唱歌时冲刺禁用（`dash` 按钮变灰）。
- 深梦层唱歌时允许冲刺，但冲刺会立刻断歌（`songBreak`）。

## 3. 体型阶

| 阶 | 名称 | 体型 | HP | 速度 | 咬合半径 | 忆质门槛 | 能吃 | 能进 |
|---|---|---|---|---|---|---|---|---|
| 0 | 茶碗 | 1.00 | 100 | 195 | 28 | 0 | 小荧鱼、梦糖、珍珠贝 | 主水道 |
| 1 | 水缸 | 1.50 | 160 | 212 | 34 | **260** | +灯笼鱼、纸船水母、宝箱 | 宽裂隙 |
| 2 | 鲸宫 | 2.20 | 240 | 228 | 42 | **760** | +夜光鳐、赤甲皇鱼（需破甲） | 一切裂隙 |

**倒退规则**：深梦层内**永不降阶**。稳度低只是掉血，不缩水。
**视觉**：每次升阶给 1.2s 时停 + 白闪 + 礼服炸开再收拢（见 `03` 第 8 节）。

### 3.1 巨口鮟鱇的例外

鮟鱇**永远不能直接吃**（无论几阶）。唯一击杀方式：
1. 鲸歌 Perfect 定身（≥2.0s）
2. 定身期间发动一次猛扑 → 播放「吞食反杀」演出（2.0s，不可跳过）
3. 获得大量忆质（90）+ 一颗「大珍珠」

这是设计上最爽的一次交互，必须做足演出。

## 4. 时间预算

| 段 | 目标时长 | 允许区间 | 超时的处理 |
|---|---|---|---|
| `BRIEF` | 15s | 0–30s | 可跳过 |
| `SURFACE` 第一区（教学） | 90s | 60–120s | 不强制 |
| `SURFACE` 主体 | 3min | 2–4min | — |
| `SURFACE` 找碎片 | 75s | 30–120s | 裂隙强制 6 分钟开启（保底） |
| `DESCENT` | 8s | 固定 | 可按 Esc 跳到 3s |
| `DEEP` 升水缸 | 90s | 45–150s | — |
| `DEEP` 升鲸宫 | 120s | 60–210s | 稳度会逼玩家走快 |
| `DEEP` 破机关 + 找旋律 | 90s | 45–150s | — |
| `BOSS` | 150s | 90–240s | — |
| `DAWN` | 25s | 10–40s | 可跳过逐行动画 |

**保底机制**：浅梦层 6 分钟时无论碎片是否集齐，裂隙都会开启（提示「梦要散了」）。深梦层 7 分钟时强制传送进 Boss 场。这不是失败，是防止卡关。

## 5. 输入

| 行为 | 键鼠 | 触屏 | 手柄（预留） | 备注 |
|---|---|---|---|---|
| 游动 | WASD / 方向键 | 左侧虚拟摇杆 | 左摇杆 | 8 向，归一化 |
| 冲刺 | Shift | 右下「冲刺」 | RT | 按住 |
| 猛扑 | J / 鼠标左键 | 「猛扑」 | X | 点按即发动，可长按连扑 |
| 鲸歌 | 按住 F / 鼠标右键 | 「鲸歌」 | B | **按住起唱，在拍点松开** |
| 海图 | Tab / 按钮 | 「图」 | Select | 暂停世界 |
| 暂停 | Esc | 「Ⅱ」 | Start | |

**猛扑节奏**：点按 = 单次前扑（冷却 0.48s）；按住 = 每 0.48s 自动再扑一次（旧版连扑保留，但每次消耗 6 点冲刺）。
**鲸歌判定**：见 `08` 第 2 节。

## 6. 失败与容错

三层失败，惩罚递进，**但不清档、不扣珍珠**：

| 失败 | 触发 | 演出 | 结果 |
|---|---|---|---|
| `RESCUED` 被惊醒（浅梦层） | 生命归零 | 画面翻白、鲸宫钟响、女仆长叹气 | 结算，珍珠 30%，任务进度保留 |
| `FADED` 梦碎（深梦层） | 稳度归零 | 画面褪成灰白、梦的碎片飞散 | 同上 |
| `DEVOURED` 被吞（Boss） | 生命归零 | 黑屏 + 执念的低语 + 「再来一次」 | 同上，但**已收集旋律碎片保留** |

**重试**：`DAWN` 界面直接「再进这个梦」，从 `DESCENT` 开始（不重打浅梦层）。这是刻意的：浅梦层收集一次就够，逼玩家重玩重复内容会毁掉节奏。

## 7. 难度曲线

每关配置 `pressure: 1..5`，影响：

| pressure | 噩梦数 | 噩梦速度 | 机关预警 | 稳度掉速 | 敌鱼攻击 CD |
|---|---|---|---|---|---|
| 1 | 1 | ×0.85 | 1.4s | ×0.8 | ×1.25 |
| 2 | 2 | ×0.95 | 1.2s | ×0.9 | ×1.1 |
| 3 | 3 | ×1.0 | 1.0s | ×1.0 | ×1.0 |
| 4 | 4 | ×1.08 | 0.85s | ×1.12 | ×0.9 |
| 5 | 5 | ×1.15 | 0.7s | ×1.25 | ×0.8 |

关卡 → pressure：浅湾 1，古渡 2，紫海 3，熔渊 4，圣殿 5。

**动态补偿**（可选，M6 再做）：连续失败 2 次后，pressure 临时 −1（只影响生命伤害与稳度掉速，不影响机关预警），通关后恢复。

## 9. 反作弊与一致性

- 逻辑步长固定 1/60s，渲染插值。`requestAnimationFrame` 只负责采样与插值，累计 `dt` 超过 0.25s 时丢弃。
- 所有随机数走 `sim/rng.js`（xorshift128），种子写入存档。这样录像/回放/自动化测试可复现。
- 不允许在渲染层修改任何 `sim` 状态。渲染只读。
