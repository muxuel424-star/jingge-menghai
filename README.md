# 鲸歌梦海

《鲸歌梦海》是一款横版 2D 深海浏览器游戏。大肥鱼可以自由穿梭五片海域，在食物链中捕食、进化并挑战首领，也可以唱睡噩梦，把迷路的梦送回月光井。

[在线游玩](https://muxuel424-star.github.io/jingge-menghai/) · [反馈问题](https://github.com/muxuel424-star/jingge-menghai/issues)

## 操作

| 操作 | 按键 |
| --- | --- |
| 游动 | WASD 或方向键 |
| 冲刺 | Shift |
| 连续猛扑（捕食模式） | 按住 J 或鼠标左键，方向键控制猛扑方向 |
| 展开海图 | Tab，或点击右下角海图按钮 |
| 鲸歌 | F。捕食模式按住蓄力，到亮线时松开 |
| 暂停 | Esc |
| 静音 | M |

触屏设备会显示屏幕按键。捕食模式里的珍珠、任务和永久升级保存在浏览器本地。

## 捕食进化

五海之间可以沿边缘洋流自由往返。每片海域包含四个区域、分层水道与可绕行的礁岛，猎物、宝箱和大型掠食者分布在不同深度。浅湾、沉船、紫晶深井、火山和鲸骨圣堂各有独立地形。

进食恢复饱食度并积累经验，进化后体型增长，可捕食的种类逐步增加。高阶猎物需要达到对应体型，大型掠食者会追猎弱小角色。连续进食可触发七秒狂食，提高得分并抵挡伤害。

首领有多套带预警的攻击和狂暴阶段。达到对应体型后，主动猛扑收招中的首领，或绕到背部突袭。鲸歌能制造短暂破绽，连续使用时首领会抵抗。随时可以从暂停菜单选择「带珍珠返航」结算本次收获。

## 海域互动与补给

浅湾的涨落潮汐、沉船区的落木和摆动舱门、紫海的旋涡与上升流、熔渊的喷发与蒸汽，以及圣堂的移动光栅和回响环会影响游动路线。危险机关先预警，再生效。礁棚、断桅、柱石和鲸骨拱洞可以穿行或绕行。

小荧鱼会惊散再聚群，灯笼鱼用光引诱鱼群并放电，夜光鳐会高速滑翔和制造涡流，赤甲皇鱼有可破坏的正面护甲，巨口鮟鱇会吸食猎物后突袭。绕后和抓住收招时机有助于捕食。

护盾抵挡两次伤害，潮汐磁铁吸引可食猎物，回声海螺标记宝箱与补给，疾游鳍符提高游速，梦糖诱饵聚拢小荧鱼，海葵药剂恢复生命。拾取后会显示效果与剩余时间。

捕食、受击、鱼类技能、环境机关、道具和首领的蓄势、出招、受伤、狂暴及击败均有对应音效。按 M 可静音。

## 本地运行

使用 Node.js 22 或更新版本。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。运行 `npm run build` 也可以生成自包含的 `dist/play.html`，双击即可离线游玩。

## 参与修改

欢迎 Fork 仓库，克隆自己的副本，修改后提交 Pull Request。角色动画和渲染在 `src/side/`，海域地形和生态配置在 `src/side/reefs.js`，2D 美术文件在 `assets/side/`。

更改游戏后可以运行 `npm run build:pages` 更新 `docs/index.html`。GitHub Pages 从 `main` 分支的 `docs/` 目录部署试玩版。
